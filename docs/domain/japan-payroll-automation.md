# 国内給与自動算定の一次資料（2026）

確認日: 2026-09-12。対象契約は [給与・勤務制度仕様](../specs/enterprise-payroll.md)。制度値は期間付き資料データとして計算snapshotへ保存する。本人の資格/扶養/標準報酬の判定を、登録がないという理由で非該当や0円にしない。

## 所得税・年末調整

- [国税庁・2026源泉徴収税額表](https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/01.htm)、[月額甲欄の電算機特例 p18](https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/data/18.pdf)。社会保険等控除後給与から電算機用給与所得控除・基礎控除・扶養控除を引き累進式で計算する。給与所得控除の1円未満は切上げ、最終税額10円未満は四捨五入。扶養数は月次の源泉控除対象人数（障害・寡婦等の人数加算も原資料で確認した値）を入力し、年末調整の扶養控除対象と同一視しない。月額甲欄だけに適用できる。
- [2026税制改正](https://www.nta.go.jp/users/gensen/2026kiso/)、[同Q&A（2026年5月）](https://www.nta.go.jp/users/gensen/2026kiso/pdf/0026005-024.pdf)。改正後の給与所得控除/基礎控除は2026年12月年調に適用。2026年11月まで月次源泉事務を変更せず、改訂月次税額表は2027年から。2026年中でも施行日前に最後の給与を受けた非居住者等の例外を分離する。
- [2026年末調整のしかた](https://www.nta.go.jp/publication/pamph/gensen/nencho2026/01.htm)、[電算機年調式](https://www.nta.go.jp/publication/pamph/gensen/nencho2026/pdf/204.pdf)。年調給与2,200,000〜6,599,999円は4,000円刻み。給与2,000万円超は対象外。課税給与所得1,000円未満を切捨て、住宅控除後税額×1.021を100円未満切捨て。徴収済税との差を還付/追加徴収として保持する。
- [2026控除表 pp55–56](https://www.nta.go.jp/publication/pamph/gensen/nencho2026/pdf/115.pdf)。2026年調の基礎控除は合計所得489万円以下104万円、655万円以下67万円、2,350万円以下62万円、それより上は48/32/16万円の段階。月次電算の基礎控除とは別表である。扶養・特定親族・配偶者・障害等の区分/合計所得条件を記録する。
- [生命保険等控除（2026年調 pp21–28）](https://www.nta.go.jp/publication/pamph/gensen/nencho2026/pdf/107.pdf)、[生命保険料控除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1140.htm)。一般生命の新旧、介護医療、新旧個人年金を分け、全体12万円限度。2026年の23歳未満扶養親族がいる新一般生命保険の拡大枠を扱う。住宅控除は税務署/年末残高等の確認済み額を入力する（借入額だけから適格を推定しない）。

## 被保険者負担

- [協会けんぽ・2026支部保険料率](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/rate_prefectures/r08/)。2026年3月保険料分から改定。加入支部で決まり、居住地や全国平均から推定しない。標準報酬決定通知の金額を使う。
- [協会けんぽ・介護料率](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/002/)。2026年3月分から1.62%、40〜64歳の第2号被保険者。年齢到達日（誕生日前日）を含む保険月と資格を確認する。
- [協会けんぽ・子ども子育て支援金](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/003/)。2026年4月保険料分から0.23%で労使折半。給与支払月と保険料対象月を区別する。従来の事業主のみの子ども子育て拠出金と混同しない。
- [日本年金機構・保険料額表](https://www.nenkin.go.jp/service/kounen/hokenryo/ryogaku/ryogakuhyo/20200825.html)、[一般の厚生年金率FAQ](https://www.nenkin.go.jp/section/faq/kounen/hokenryo/20120329.html)。厚生年金率18.3%、原則労使折半。給与控除の被保険者負担の端数は50銭以下切捨て、50銭超切上げ（特約は別確認）。本機能は通常の給与控除端数に限定する。
- [厚労省・2026雇用保険料率](https://www.mhlw.go.jp/content/001692566.pdf)。2026年4月〜2027年3月、労働者は一般5/1000、農林水産・清酒/建設6/1000。酪農等の例外は一般区分になるため、業界テンプレート名から自動推定しない。

## 勤務制度

- [厚労省兵庫局・1か月変形](https://jsite.mhlw.go.jp/hyogo-roudoukyoku/hourei_seido_tetsuzuki/roudoukijun_keiyaku/_79872/1kagetsu.html)。1か月以内の期間、起算日、法定総枠内の各日/各週所定をあらかじめ特定する。
- [厚労省・時間外の計算Q&A](https://www.mhlw.go.jp/content/11200000/tp1216-1l-02.pdf)。変形は日ごとに所定が8h超なら所定、そうでなければ8hの超過を算定し、週では所定40h超なら所定を基準に日超過分を除外、期間総枠から日/週超過を除外する。
- [厚労省・複数月フレックスの時間外](https://www.check-roudou.mhlw.go.jp/qa/roudousya/roudoujikan/q3.html)、[フレックスの基本](https://www.check-roudou.mhlw.go.jp/study/roudousya_tayou_flex.html)。清算3か月以内。1か月超なら月ごとの週平均50h超、最終月は全期間法定総枠超から既算定時間外を控除する。法定休日は清算時間外とは別枠。始終業時刻の自主選択を固定シフトで置き換えない。

## 未確認を明示する範囲

2027年以後の制度データは2026資料から外挿しない。保険資格届・標準報酬等級の決定そのもの、住民税課税決定、税務申告の送信、特殊な年末調整の適格判定、労使合意/届出の法的有効性は本計算だけでは確定しない。対象外を自動計算0円として扱わない。


## 追加の照合と入力区分

- [協会けんぽ・大分の2026額表](https://www.kyoukaikenpo.or.jp/assets/R8_44oita.pdf)で健康保険50等級（58,000〜1,390,000円）、厚生年金32等級（88,000〜650,000円）、給与控除の端数と一般18.3%を照合した。健康保険と介護の合算額を表どおりに丸め、その合算から健康保険額を引いて介護内訳とする。厚生年金基金加入員の免除率を通常加入へ流用しない。
- [協会けんぽ・40/65歳の到達月](https://www.kyoukaikenpo.or.jp/shibu/ibaraki/public_relations/009/)のとおり誕生日前日が属する月から介護の加入/終了を切り替える。3月1日生まれは2月分で変わる。75歳の後期高齢者資格は誕生日基準なので同じ到達日前日と混同しない。
- [厚労局・労働保険年度の区分](https://jsite.mhlw.go.jp/yamagata-roudoukyoku/content/contents/002587832.pdf)は賃金支払日でなく締切日による。本実装は月末締切のため、3月給与を4月に支払っても雇用保険は旧年度料率を選ぶ。
- [勤労学生](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1175.htm)は2026年末に所得89万円以下、勤労以外の所得10万円以下、控除27万円。学生の学校要件等は本人の申告と給与本部の受付で確認する。
- [所得金額調整控除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1411.htm)は850万円超の給与、対象親族等を確認し、上限1,000万円との差×10%を1円未満切り上げる。夫婦双方に適用し得る。
- `107.pdf` はWeb取得のタイムアウト後、公式URLを直接取得してPDF本文も確認した。生命保険は新/旧/合算の最も有利な控除を選び、各算定額の1円未満を切り上げる。子の特例は夫婦双方に適用できるので、親族の「この本人が扶養控除を申告する」指定と分ける。地震/旧長期が同一契約の場合は一方のみを申告し、入力の確認フラグを根拠なしに選択しない。
- 保険料申告額は本人が支払った適格額から配当・割戻を差し引き、区分を正しく分けた年額。前納保険料の年割り・証明書取得・住宅控除適格の判定は原資料による確認が必要。給与天引き社会保険は自動集計し、直接支払の社会保険へ重複入力しない。
