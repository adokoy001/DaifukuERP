# 商流の操作と参照資料

確認日: 2026-09-13。以下は製品ワークフローを比較した設計根拠であり、日本の会計・税法への適合認証ではない。

- [ERPNext Delivery Note](https://docs.frappe.io/erpnext/delivery-note): 注文を複数の納品に分ける partial delivery と、残数を送らない short close を別操作として扱う。本実装も分納と残数打切りを区別する。
- [ERPNext Purchase Receipt](https://docs.frappe.io/erpnext/purchase-receipt): 入荷確定で在庫台帳と発注残数を更新し、後続の仕入請求を作成する。本実装は履行時の在庫と請求時の債務を別文書として追跡する。

例: 10個を発注→6個入荷→入荷の4個分だけ仕入請求→残り2個分を請求→注文の4個を追加入荷。最初の請求を取り消しても入荷6個は残る。入荷を取り消すには、先にその入荷の全請求を取り消す。受注と出荷も同じ残数契約を使う。

在庫評価は既存移動平均・時系列制約を継承する。入荷の合意税抜単価を評価単価に用い、請求日の税率・丸めにより注文見込額と請求額が違う場合がある。仕入請求で在庫を二度受け入れない。返品・価格差異・棚卸資産会計の追加は別設計を要する。


## 試す一連の業務

1. 販売対象または購買対象の物品を固定在庫単位で登録し、取引先の得意先／仕入先区分、倉庫、会計年度、税率・勘定設定を用意する。
2. 発注10個×税抜600円を作成・確定する。6個を入荷すると在庫は6個増える。4個だけ仕入請求すると標準税率10%の試験設定では税込2,640円、同入荷の2個を追加請求すると税込1,320円。請求による在庫増加はない。
3. 元発注の残り4個を入荷するか、不要なら理由を記録して残数を打ち切る。打切りは物品や既請求を取り消さず、既入荷の未請求は引き続き請求できる。
4. 販売側は見積10個×税抜1,000円を確定して受注下書きへ変換し、確認後に受注を確定する。6個出荷し、そのうち4個を請求すると、受注残4個・出荷済未請求2個となる。在庫は出荷時に一度だけ減る。
5. 訂正は入出金→商流請求→出荷／入荷→注文の依存順に扱う。請求だけを取り消した時点では在庫は変わらない。取消有効日より前への再計上は拒否する。銀行照合済み入出金には銀行側の照合取消も必要となる。

いずれも検収の成立、収益認識要件、返品、銀行の送金実行を自動判定するものではない。
