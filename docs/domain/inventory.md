## 評価方法の種類（原価法 6 種と低価法）
- 法人: **法人税法施行令 第28条第1項** —（棚卸資産の評価の方法）第1号 原価法: イ 個別法、ロ 先入先出法、ハ 総平均法、**ニ 移動平均法**、ホ 最終仕入原価法、ヘ 売価還元法。第2号 低価法。— e-Gov API `lawNum=昭和四十年政令第九十七号;article=28`（WebFetch 2026-09-11）
- 個人: **所得税法施行令 第99条第1項** — 同じ 6 種（イ〜ヘ）と第2号 低価法。— e-Gov API `lawNum=昭和四十年政令第九十六号;article=99`（WebFetch 2026-09-11）
- <a id="moving-average"></a>**移動平均法の定義**（法令28条1項1号ニ）: 「移動平均法（棚卸資産をその種類等の異なるごとに区別し、その種類等の同じものについて、当初の一単位当たりの取得価額が、再び種類等を同じくする棚卸資産の取得をした場合にはその取得の時において有する当該棚卸資産とその取得をした棚卸資産との数量及び取得価額を基礎として算出した平均単価によつて改定されたものとみなし、以後種類等を同じくする棚卸資産の取得をする都度同様の方法により一単位当たりの取得価額が改定されたものとみなし、当該事業年度終了の時から最も近い時において改定されたものとみなされた一単位当たりの取得価額をその一単位当たりの取得価額とする方法をいう。）」（WebFetch 2026-09-11、上記の注記どおり逐語は要約モデル経由）
  - → **取得（受入）のたびに**「手持ちの数量・取得価額」と「受け入れた数量・取得価額」から平均単価を改定する。払出では単価を改定しない。`modules/inventory/src/services/moving-average.ts` の inbound / outbound がこの形。
- 総平均法（同ハ）は「期首の取得価額の総額と期中の取得価額の総額の合計額を総数量で除した価額」（WebFetch 2026-09-11）。本モジュールは実装しない（スコープ外）。
- 低価法（同第2号）は「原価法により評価した価額と事業年度終了の時における価額とのうちいずれか低い価額」（WebFetch 2026-09-11）。実装しない。

## 法定評価方法（届け出なかった場合）と選定・届出
- **法人税法施行令 第31条第1項**:「…評価の方法を選定しなかつた場合又は選定した方法により評価しなかつた場合における政令で定める方法は、第二十八条第一項第一号ホ…に掲げる**最終仕入原価法**により算出した取得価額による原価法とする。」（WebFetch 2026-09-11）
- **所得税法施行令 第102条第1項**: 同旨（第九十九条第一項第一号ホの最終仕入原価法による原価法）。（WebFetch 2026-09-11）
- **法人税法施行令 第29条**: 第1項 評価の方法は「事業の種類ごとに、かつ、商品又は製品、半製品、仕掛品、主要原材料及び補助原材料その他の棚卸資産の区分ごとに選定しなければならない」。第2項 所定の日の属する事業年度の「申告書の提出期限までに」「書面により納税地の所轄税務署長に届け出なければならない」。（WebFetch 2026-09-11）
- **所得税法施行令 第100条**: 第1項 同旨（事業の種類・資産の区分ごと）。第2項 所定の日の属する年分の「確定申告期限までに」届出。（WebFetch 2026-09-11）
- 変更の承認申請（法令30条・所令101条）は取得していない【未確認】。
- → **業務上の注意**: 何も届け出ていない会社の税務上の評価は最終仕入原価法。本モジュールの在庫評価（移動平均法）を申告に使うなら移動平均法の届出が要る。`inventory.valuation` はあくまで帳簿上の移動平均の金額。最終仕入原価法の評価額レポートは未実装（判断待ち）。

## 取得価額（購入した棚卸資産）
- **法人税法施行令 第32条第1項第1号**: 購入した棚卸資産の取得価額は「イ 当該資産の購入の代価（引取運賃、荷役費、運送保険料、購入手数料、関税その他当該資産の購入のために要した費用がある場合には、その費用の額を加算した金額）」と「ロ 当該資産を消費し、又は販売の用に供するために直接要した費用の額」の合計額。（WebFetch 2026-09-11）
- → 本モジュールの自動入庫は**仕入請求書の明細の税抜単価だけ**を受入単価にする（spec AC-5）。同じ請求書の運賃・手数料の行（経費行・サービス品目）は在庫の取得価額に**配賦しない**。付随費用を含めたい場合は、入出庫伝票（入庫・調整）の単価で手当てするか、配賦機能（スコープ外）が要る。
- 消費税: 税抜経理を前提に税抜単価で受け入れる（税込入力の請求書は `unitPrice ÷ (1 + 税率)` を 6 桁で丸める）。免税事業者からの仕入の**控除対象外消費税**を取得価額に含めるかは扱わない（purchase モジュールは費用科目に計上する）【未確認: 出典未取得】。

## 売上原価と三分法
- 売上原価 = 「年初（期首）の棚卸高＋年間の仕入高 −年末（期末）の棚卸高」（p.1）。「評価方法を届け出ていない場合は、次の最終仕入原価法により評価することになります。」（p.2）— 国税庁「令和６年分 青色申告の決算の手引き（一般用）」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2024/pdf/025.pdf （WebFetch 2026-09-11。PDF を要約モデル経由で抽出、逐語は未目視）
- 三分法（仕入高・売上高・繰越商品の 3 勘定。期中は仕入時に仕入高、期末に「仕入 / 繰越商品」「繰越商品 / 仕入」の決算整理）は簿記の慣行【未確認: 一次出典を取得していない】。
- → 本モジュールは**仕訳を切らない**（spec）。仕入は purchase が仕入高（5000）に、売上は sales が売上高（4000）に転記済み。`inventory.valuation { asOf }` の合計が期末商品棚卸高の元。決算整理仕訳は accounting で手入力するかパックのアクションで行う。

## 実装上の決め（出典のない設計判断。docs/log/2026-09-11-inventory.md に理由）
- 平均の単位は**品目 × 倉庫**（spec AC-1 の stock_balance）。法令の「種類等ごと」は品目単位なので、倉庫をまたぐと会社全体の単一の移動平均とは一致しない（倉庫ごとの平均で払い出すため）。移動は払出時の原価をそのまま移動先に受け入れるので金額の合計は保存される。`inventory.valuation` は倉庫合計の Σ金額 ÷ Σ数量を平均単価として表示する。【判断待ち】税務上の評価を品目単位の単一平均にするか。
- 端数: 平均単価・金額とも小数 6 桁で四捨五入（列は numeric(20,6)）。在庫金額は台帳の金額増減の合計そのもの（数量 × 平均単価ではない）で、最後の 1 単位の払出が残額をすべて持ち出す（数量 0 ⇒ 金額 0）。法令に端数処理の定めは見当たらない【未確認】。
- 取消は逆行を追記する（ADR-0005）。受入の取消は「その受入の原価」を戻して平均を再計算、払出の取消は「その払出の原価」を戻す。取消した受入の後に行われた払出の単価は**再計算しない**（再評価・遡及計算はスコープ外）。golden の第 3 シナリオ（10@100, 10@120, 払出 5 → 2 回目の受入を取消 → 平均 90）がこの帰結。
- 移動平均は**転記（submit）順**に計算する。過去日付の伝票を後から submit しても後続行は再計算しない。`stock_on_hand { asOf }` と `valuation { asOf }` は日付で台帳を集計する（Σ数量・Σ金額、平均 = 金額 ÷ 数量）ので、順序に依存しない。
- マイナス在庫（設定 `inventory.allow_negative_stock`、既定 false）: 在庫がマイナスの間は平均単価を固定し金額 = 数量 × 平均単価。マイナスを解消する受入は、残った数量を受入単価で評価し直す（穴埋め分との差額は在庫金額に残さない）。受入実績のない品目のマイナス払出は単価 0。
