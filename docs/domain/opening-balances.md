# 期首残高（他システムからの移行時の開始残高）— 設計に効く制度事実

2026-10-30 作成（[opening-balances](../specs/opening-balances.md) の spec 作成時）。各項目に出典と確認日を付ける。

**取得の制約**: この作成セッションからは `www.nta.go.jp` と `laws.e-gov.go.jp` に接続できなかった（DNS 解決不可。セッションのネットワーク設定で許可されていない）。そのため、既存の docs/domain で確認済みの事実を参照し、新しく必要になった事実は【未確認】と明記して、確認すべき一次出典の URL を付けた。実装セッションか統合担当が一次出典を取得できたら、本文の引用と確認日に置き換える。

## 消費税: 期首残高は新しい取引ではない（不課税として扱い、税額を出さない）

<a id="consumption-tax"></a>

- 確認済み: 消費税の課税区分には課税・非課税・免税・**不課税**がある — 国税庁 タックスアンサー No.6201（[japan-tax.md](japan-tax.md) の「消費税」、確認 2026-09-10）。
- 確認済み: 消費税集計表は「区分経理された帳簿」（仕訳の税区分・税率）から作る — [japan-tax.md#tax-period-summary](japan-tax.md#tax-period-summary)（確認 2026-09-11）。
- 【未確認】課税の対象は「国内において事業者が行つた資産の譲渡等」（消費税法 第4条第1項）で、資産の譲渡等は「事業として対価を得て行われる資産の譲渡及び貸付け並びに役務の提供」（同法 第2条第1項第8号）。— e-Gov 法令検索 消費税法（昭和六十三年法律第百八号） https://laws.e-gov.go.jp/law/363AC0000000108 、国税庁 タックスアンサー No.6105「課税の対象」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6105.htm （2026-10-30 に取得を試みたが接続できず。条文の文言は記憶による）
- → 設計: 期首の売掛金・買掛金は、前期以前に行った取引（その課税期間で消費税を処理済み。残高は税込額）の未決済残高であり、期首に新しい資産の譲渡等が行われたわけではない。期首請求書の明細は税区分 `out_of_scope`（不課税）・税額 0 とし、日付は期首日の前日（どの会計期間・課税期間にも入らない日）にする。これにより当期の消費税集計表と、免税事業者からの仕入れの経過措置（[japan-tax.md](japan-tax.md) のインボイス制度）の年間累計に入らない。

## 適格請求書（インボイス）との関係: 期首請求書は発行する書類ではない

<a id="qualified-invoice"></a>

- 確認済み: 適格請求書の記載事項は 6 項目、登録番号は `T` + 13 桁 — 国税庁 タックスアンサー No.6625（[japan-tax.md](japan-tax.md)、確認 2026-09-10）。
- 【未確認（項目の列挙はこのセッションで再確認していない）】6 項目は ①適格請求書発行事業者の氏名又は名称及び登録番号 ②取引年月日 ③取引内容（軽減税率の対象品目である旨）④税率ごとに区分して合計した対価の額（税抜き又は税込み）及び適用税率 ⑤税率ごとに区分した消費税額等 ⑥書類の交付を受ける事業者の氏名又は名称。請求書番号（連番）は記載事項に含まれない。— No.6625 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6625.htm
- 【未確認】適格請求書発行事業者は、課税資産の譲渡等を行った相手方（課税事業者）から求められたときに適格請求書を交付する（消費税法 第57条の4）。適格請求書と誤認されるおそれのある書類の交付は禁止される（同法 第57条の5）。— 同上の e-Gov 消費税法
- → 設計: 期首請求書は、移行前に既に交付した請求書の未入金残高を消込・年齢表で扱うための社内の記録であり、取引先へ交付しない。日付は元の取引年月日ではなく期首日の前日なので、適格請求書として印刷すると記載事項②が事実と異なる書類になる。したがって `sales.render_invoice_html` は期首請求書を描画しない（spec AC-20）。採番は通常の連番（`INV-` / `BILL-`）を使う。記載事項に番号が含まれないため、期首請求書が連番の一部を使っても制度上の要件には触れない、という読み【未確認: 上記の列挙に依存】。
- → 仕入側: 期首の買掛金は前期以前の課税仕入れの残高で、仕入税額控除（適格請求書等の保存）は元の取引の課税期間で判断済み。期首請求書（不課税・税額 0）は当期の控除額の計算に入らない。

## 損益科目は繰り越さない（期首残高は貸借対照表の科目だけ）

<a id="no-pl-carry"></a>

- 確認済み: 本システムの申告準備（財務諸表の出力）は「損益振替前・期首損益残高ゼロの年度試算表」を対象とし、「期首損益科目残高ゼロと当期損益振替前の確認を要」する — [japan-tax-filing.md](japan-tax-filing.md)（検証 2026-09-13）。
- 【未確認: 一次出典を取得していない】収益・費用の勘定は期末に締め切り、当期の損益は法人は繰越利益剰余金、個人事業者は元入金へ含めて翌期に繰り越す（簿記の慣行）。個人事業者の翌年の期首の元入金は「期首の元入金 + 青色申告特別控除前の所得金額 + 事業主借 − 事業主貸」で計算し、事業主貸・事業主借は翌年の期首に残高を持たない。— 国税庁「令和６年分 青色申告の決算の手引き（一般用）」貸借対照表の記載方法 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2024/pdf/025.pdf （[inventory.md](inventory.md) が同じ PDF の別の頁を 2026-09-11 に要約経由で確認済み。元入金の頁は未確認）
- → 設計: 開始仕訳の取込は区分 `revenue` / `expense` の科目の行を拒否する（spec AC-9）。事業主貸・事業主借は区分が `equity` のためシステムは検査せず、マニュアル 03 で注意する。

## 在庫の期首数量と単価

<a id="opening-stock"></a>

- 確認済み: 移動平均法は、当初の一単位当たりの取得価額から始め、取得のたびに手持ちと受入の数量・取得価額から平均単価を改定する方法 — 法人税法施行令 第28条第1項第1号ニ（[inventory.md#moving-average](inventory.md#moving-average)、2026-09-11、要約モデル経由の引用）。
- 確認済み（本システムの実装上の決め）: 移動平均は転記順に計算し、過去日付の伝票を後から確定しても後続の払出の単価は再計算しない — [inventory.md](inventory.md) の「実装上の決め」。
- → 設計: 期首在庫は、期首日の前日付の入庫として品目 × 倉庫ごとに最初に転記し、その単価を移動平均の当初の取得価額にする。期首日の前日より後の在庫移動が既にある品目 × 倉庫は取り込まない（spec AC-23。後から入れると既存の払出の単価が期首の単価を反映しないため）。
- 確認済み: 評価方法を届け出ていない場合の法定評価方法は最終仕入原価法 — [inventory.md](inventory.md)（法令31条、2026-09-11）。→ 前期を最終仕入原価法で評価していた会社は、その単価を期首単価として取り込むことになる。移動平均法への変更の手続（届出・承認申請）は利用者が判断する【未確認: 変更承認申請（法令30条）は未取得。inventory.md と同じ】。
