# docs/ — system of record

| Dir | 何が入るか | いつ読む |
|---|---|---|
| `adr/` | アーキテクチャ決定記録（決定・根拠・確信度・最強の反論） | 設計に触る前 |
| `conventions/` | レイヤ・命名・エラー・テスト・金額日付・lint の規約 | コードを書く前 |
| `domain/` | 用語集（ja/en）、日本の制度事実（出典URL・日付つき） | 業務ロジックを書く前 |
| `specs/` | 1機能1仕様（EARS 受入基準・スコープ外・検証手順） | 実装前に書く |
| `log/` | 作業記録（決定・検証方法・未実施・判断待ち） | 実装後に書く、次セッション冒頭に読む |
| `metrics/` | 機能ごとの計測値（jsonl） | 週次集計 |
| `experiment.md` | 実験の仮説・観測履歴と中止基準 | 週次レビュー |

計画書本体（Phase 計画・スタック・リスク）は `../PLAN.md`。
