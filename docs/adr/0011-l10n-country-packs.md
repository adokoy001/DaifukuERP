# ADR-0011: 国パック（l10n）の構造。日本を最初に、唯一の実装として作る

- 状態: 採択／ 確信度: 高
- 出典: research/01 §1（Odoo `l10n_xx`、ERPNext regional）、research/04（日本要件）

## 決定
`l10n/<cc>` は次を1パッケージで宣言する: 勘定科目表テンプレート／税コード（率×適用期間、課税区分、用途区分）／fiscal position（取引相手・品目による税の置換）／帳票レイアウト（適格請求書・簡易・返還）／銀行フォーマット（全銀120バイト）／電子インボイス出力（JP PINT）／法定パラメータ（経過措置控除率テーブル、少額特例等、施行日つき）／表示規則（和暦、半角カナ正規化、郵便番号）／振る舞いの差し替え（`registerOverride`）。

## 制約
税率・控除率・閾値は**必ず有効期間つきのデータ**として持つ（2027-04 の飲食料品1%案が未成立のまま設計に影響するため、率の追加が設定だけで済むことを golden test で担保する）。
