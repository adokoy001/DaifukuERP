# 付録 B 台本の要約（何を入力すると何が出るか）

大福帳には、業務の流れと計算の正しさを確かめるための練習用の取引データ（台本）が 3 本あります。どれも架空の事業者で、期待する数字はすべて開発者が手で計算し、自動テストが同じ数字になることを確かめています。台本の全文は `docs/domain/scenario-kojin.md`、`scenario-retail.md`、`scenario-real-estate.md` にあります。

この付録の数字は **台本と自動テストの数字** です。この文書のスクリーンショットは、複数の台本とテストのデータが同居したデモ環境で撮ったため、画面の金額とは一致しないことがあります。

## 1. 個人事業（デザイン事務所、2026 年 10 月）

**入力するもの**

- 取引先 6 件（顧客 3、仕入先 3。うち 1 件は免税事業者、1 件は 20 日締め翌月 10 日払い）、品目 4 件（サービス 2、書籍、軽減税率の菓子）
- 期首の元入金 300,000 円（仕訳）
- 売上請求書 4 件（税抜入力）: 150,000 円、30,000 円、59,000 円、軽減税率 1,111 円 × 3 行
- 仕入・経費の請求書 4 件（税込入力）: 名刺印刷 22,000 円、免税事業者の撮影 55,000 円、家賃（非課税）80,000 円、会議用飲料（軽減）5,400 円
- 入出金 3 件（入金 33,000 円、支払 22,000 円・80,000 円）
- 在庫は使わない設定

**出てくるもの**

| 項目 | 期待値 |
|---|---|
| 売上 税抜 / 消費税 / 税込 | 242,333 / 24,166 / 266,499 円 |
| 軽減税率 3 行の消費税 | **266 円**（税率ごとに 1 回丸め。行ごとに丸めると誤って 264 円） |
| 免税事業者の仕入 55,000 円 | 控除 3,500 円（70%）、控除対象外 1,500 円は外注費に含める |
| 20 日締め翌月 10 日払いの 10/20 の請求 | 支払期日 11/10 |
| 試算表の合計（借方 = 貸方） | 863,899 円 |
| 消費税集計 | 売上税額 24,166、仕入税額 5,900、差引 18,266 円。家賃 80,000 円は非課税の行（税額 0） |
| 月末残高 | 売掛金 233,499、買掛金 60,400、普通預金 231,000 円 |
| 損益 | 売上 242,333 − 費用 156,500 = 85,833 円 |
| 適格請求書 | 登録番号 T1234567890123、税率ごとの対価と税額、宛名、支払期限 |

## 2. 小売（食品雑貨店「まめや」、2026 年 11 月）

**入力するもの**

- 小売テンプレートを適用（店頭客、仕入先、勘定科目 5050/5100/6990、品目 4 件: 弁当・お茶は軽減税率、雑貨・文具は標準税率、売価は税込）
- 期首の元入金 200,000 円、仕入 1 件（税抜 41,000 円、自動入庫）
- レジ締め 3 件（11/5: 現金 20,000・カード 4,460 円、11/15: 全額現金、11/25: 全額カード・文具 1 個の返品を含む）
- 仕入代金の支払、月末の棚卸（弁当 1 個紛失、返品された文具が 1 個多い）、月次締め

**出てくるもの**

| 項目 | 期待値 |
|---|---|
| 11 月の売上 税抜 / 消費税 / 税込 | 57,450 / 5,040（8%: 2,820、10%: 2,220）/ 62,490 円 |
| 現金 / カード | 53,730 / 8,760 円（カード分は売掛金に残る） |
| 日次売上 | 営業日ごとの税抜・税率別の税額・現金・カード（3 日分） |
| 棚卸差異 | 弁当 −1（−300 円）、文具 +1（+150 円。返品が在庫に戻らない制限の表れ） |
| 在庫評価（期末商品棚卸高） | 7,700 円 → 仕訳「商品 7,700 / 期末商品棚卸高 7,700」 |
| 試算表の合計 | 413,200 円 |
| 消費税集計 | 売上税額 5,040、仕入税額 3,640、差引 1,400 円 |
| 売上総利益 | 売上 57,450 − 売上原価 33,300 = 24,150 円 |

## 3. 不動産（賃貸管理「サンプルハイツ」、2026 年 11 月）

**入力するもの**

- 不動産テンプレートを適用（物件 1、部屋 4: 住宅 101・102、事務所 201、駐車場 P1。入居者 4 人と賃貸借契約 4 件）
- 契約の確定、入居処理（102 は 11/11 入居で礼金 65,000 円・敷金 1 か月、201 は礼金 100,000 円・敷金 2 か月）、既存入居者 101 の 11 月分請求
- 家賃の入金 3 件（駐車場 P1 は入金しない）、11/25 に 12 月分の請求書を一括作成
- （台本の後）102 の退去と、敷金 65,000 円から 22,000 円を差し引いた返還

**出てくるもの**

| 項目 | 期待値 |
|---|---|
| 102 の 11 月分 | 家賃 65,000 × 20/30 = 43,333 円（切捨て）＋ 礼金 65,000 円、どちらも非課税 |
| 201 の 11 月分 | 家賃 100,000 ＋ 礼金 100,000 ＋ 消費税 20,000 = 220,000 円（1 枚、税率ごとに 1 回丸め） |
| 11 月分の請求 合計 | 税抜 376,333、消費税 20,800、税込 397,133 円 |
| 預り金（敷金） | 265,000 円（請求書・売上には入らない） |
| 消費税集計（11 月） | 課税売上 208,000・税 20,800、非課税売上 168,333 円。12 月分（請求日 12/1）は 11 月に入らない |
| 滞納一覧（12/5 時点） | 駐車場 P1 の 11 月分 8,800 円・延滞 5 日のみ（12 月分は期日前なので入らない） |
| レントロール（11/30 時点） | 4 部屋入居中、月額合計 233,000 円（課税 108,000・非課税 125,000） |
| 試算表の合計（11 月） | 1,550,466 円 |
| 敷金返還の仕訳 | 預り金 65,000 / 普通預金 43,000・雑収入 22,000 |

---

検証: この付録の数字は台本（`docs/domain/scenario-*.md`）からの転記で、自動テストが一致を確認していると開発記録にある（このセッションでテストは再実行していない）。2026-09-11 に実機で同じ操作をして一致を確認できたのは次の数字: 個人事業の免税事業者控除（3,500/1,500）と 20 日締めの期日、小売の 3 回のレジ締めと日次売上の全行・棚卸差異、不動産の 102 の日割り（43,333＋65,000）・201 の 220,000 円・12 月分の 4 件・11 月の消費税集計・滞納一覧・レントロール・敷金返還の額。デモ環境には他のデータが同居しているため、試算表の合計・在庫評価・消費税集計（個人事業・小売）は台本の数字と比べていない。
