# 付録 O 固定資産と減価償却

固定資産を台帳に登録し、会計期間ごとに減価償却を試算・実行して仕訳を作り、除却・売却を記帳し、1 月の償却資産申告に使う集計を出す手順です（spec [fixed-assets](../specs/fixed-assets.md)、2026-10-30 追加）。経理または管理者の役割の利用者が使えます。閲覧の役割の利用者は台帳・試算・帳票を見られますが、実行・登録・CSV 出力はできません。

## できること・できないこと

- 償却方法は **定額法**（2007 年 4 月 1 日以後の取得）と **200% 定率法**（2012 年 4 月 1 日以後の取得）です。期中に事業の用に供した年は月割（1 か月未満の端数は 1 か月）、残存は 1 円（備忘価額。ソフトウエアは 0 円）、定率法は償却保証額を下回った年から改定償却率に切り替えます。年額は円未満を切り捨てます。
- 旧定額法・旧定率法・250% 定率法、特別償却、少額減価償却資産の特例、一括償却資産、1 年未満の事業年度、一部除却、償却資産申告書そのもの（eLTAX）・評価額・税額の計算はできません（[10 制限事項](10-limitations.md) も参照）。
- 取得の仕訳は作りません。仕入請求書の明細の勘定科目に資産科目（例: 1925 工具器具備品）を指定するか、仕訳を手入力します。台帳への登録は仕訳を作りません。

## 最初に確認すること（償却の規則の照合）

償却率・改定償却率・保証率・備忘価額・資産の種類ごとの償却方法の制限と、それぞれを適用する取得日は、日本の国別パック（l10n-jp）が期間付きのデータとして持っています。**2026-10-30 時点で、このデータは一次資料（e-Gov の「減価償却資産の耐用年数等に関する省令」別表第八・第十、「法人税法施行令」）と照合されていません**（開発時に一次資料へ接続できなかったため。開発資料 `docs/domain/japan-fixed-assets.md`）。年額・月の配分・除却の年の限度額の円未満を切り捨てる扱いも、出典の箇所を確認できていません。そのため、会社の担当者がこれらを照合して記録するまで、償却の実行と除却・売却の確定（仕訳の作成）は止まります。試算・登録・帳票は使えます。

1. 「償却の実行」画面の下にある「償却の規則を見る」を開き、次をすべて一次資料と照合します（出典の URL はリンクになっています）。
   - 定額法・定率法（200%）の率表: 耐用年数ごとの償却率・改定償却率・保証率と、表を適用する取得日 — 省令（https://laws.e-gov.go.jp/law/340M50000040015 ）の別表第八・第十
   - 備忘価額（有形 1 円・無形 0 円）と適用する取得日 — 法人税法施行令（https://laws.e-gov.go.jp/law/340CO0000000097 ）第61条・第48条の2
   - 償却方法の制限（建物、2016 年 4 月以後取得の建物附属設備・構築物、ソフトウエアは定額法だけ）と適用する取得日 — 同 第48条の2
   - 端数処理: 年額・月の配分・除却の年の限度額を円未満切り捨てにすること（限度額を超えない扱い）
2. 「設定」の「会計」タブで「償却率表の照合記録」に、帯に出ている規則集合の id（例: `jp-2026-10-30`）と照合した日（例: `2026-11-01`）を入れて保存します。記録は設定の変更履歴（変更者・日時）に残ります。
3. 「償却の実行」画面に戻ると帯が黄色（会社の照合記録に基づいて転記）になり、実行できるようになります。

国別パックが照合済みの率表に更新されると規則集合の id が変わり、帯は消えます（会社の記録は不要になります）。導入チェック（[08 管理](08-admin.md)）の「減価償却の規則（償却率表）」も同じ状態を示します。

## 勘定科目

新しく作った会社には次の科目が初期設定で入ります。設定「固定資産の転記科目」（「会計」タブ）で、補完と転記に使う科目コードを変えられます。

| コード | 科目 | 区分 |
| --- | --- | --- |
| 1910 | 未収入金（売却代金の既定） | 資産 |
| 1920〜1925 | 建物・建物附属設備・構築物・機械装置・車両運搬具・工具器具備品 | 資産（有形固定資産） |
| 1929 | 減価償却累計額（有形固定資産の累計額の既定） | 資産 |
| 1930 | ソフトウエア（直接法: 累計額も同じ科目） | 資産（無形固定資産） |
| 6700 | 減価償却費 | 費用（不課税） |
| 8100 | 固定資産売却益 | 収益（特別利益） |
| 8200 / 8300 | 固定資産売却損 / 固定資産除却損 | 費用（特別損失、不課税） |
| 2200 | 仮受消費税（売却の消費税） | 負債 |

**この機能より前に作った会社**には 1910〜1930・8100〜8300 が自動では入りません（科目の初期設定は会社を作るときだけ動くため）。「会計・資金」の「勘定科目」で上の表の科目を作るか、設定「固定資産の転記科目」を既にある科目コードに向けてください。科目が無いまま資産を登録・確定すると「account 1929 (fixed_assets.accounts.accumulated) does not exist」のように、設定のどの項目のどのコードが無いかを示して止まります。

## 資産を登録する

「会計・資金」の「固定資産台帳」（メニューの「固定資産」→「固定資産台帳」）で「新規」を押します。

1. 「基本」: 資産番号（後から変えられません）、名称、資産の種類、取得日、事業供用日。事業供用日が空の資産は未供用として償却しません。
2. 「償却」: 取得価額（税抜・円単位）、償却方法、耐用年数。耐用年数は資産ごとに入力します（「償却の実行」画面の「償却の規則を見る」に耐用年数の例の表があります。照合の後も見られます）。建物・2016 年 4 月以後取得の建物附属設備と構築物・ソフトウエアは定額法だけです。
3. 「勘定科目」: 資産科目は必須です。減価償却累計額科目と減価償却費科目は空なら設定から補います（ソフトウエアの累計額科目は資産科目）。
4. 「所在と申告」: 設置場所、所在市区町村、償却資産申告の種類（空なら資産の種類から補います。建物・建物附属設備・車両・ソフトウエアは「対象外」）。
5. 「移行」: システムを使う前から償却している資産は、移行日（会計期間の初日）、移行日の前日までの償却累計、そのうち移行年度に計上した額を入れます。定率法で既に改定償却率に切り替わっている資産は「移行時の改定取得価額」も入れます（入力が要るときは保存時に案内が出ます）。締め済みの会計年度に事業供用した資産は、移行日が無いと保存できません。会計年度を開く前に登録・取込した資産で、事業供用が最初の会計年度より前のものは、移行日が無いと償却されず（「償却の実行」画面に件数と案内が出ます）、除却・売却も確定できません。移行時の値を入れてください。

保存すると「状態」の節に償却開始（事業供用日と移行日の遅い方の月の初日）が入ります。償却か除却・売却を一度でも確定した資産は、名称・設置場所・所在市区町村・申告の種類・メモ以外を変更できず、削除もできません（取り消した後でも削除はできません）。

多数の資産は「インポート」（CSV 取込、[04 マスタ](04-masters.md)）で登録できます。勘定科目の列は科目コード（例: `1925`）で書けます。行ごとに上と同じ補完と検査が行われ、問題のある行はエラーとして返ります。

## 償却を実行する

「会計・資金」から「償却の実行」を開きます（「すべての画面を探す」で「償却」と検索しても出ます）。

1. 「会計期間」で期間を選びます。最初は、今日より前に終わった最後の期間です（URL の `?periodId=` にも入ります）。
2. 表に、資産ごとの償却方法・期首帳簿価額・年額・年度の計上済み額・今回の額・科目（償却費 / 減価償却累計額のコード、例 `6700 / 1929`）と合計が出ます。同じ年度で前の月を実行していなければ、その分も今回の額に入ります（例: 11 月を飛ばして 12 月を実行すると 2 か月分）。前の年度の未計上分は繰り越しません。前の年度に未計上が残っているときは注意と、その年度の最終期間へのリンクが出ます。
3. 「償却を実行」を押し、確認画面で期間・件数・合計を確かめて「実行する」を押します。償却費科目ごとの借方と累計額科目ごとの貸方に集約した仕訳が 1 本、期間の末日の日付でできます。結果はこの期間の実行の一覧に番号（DR-…）と仕訳へのリンクで出ます（画面の読み上げでも知らせ、焦点は期間の見出しへ移ります）。試算の取り直しに失敗したときは、表示が前回の結果である旨が出て、やり直すまで実行できません。会計年度がまだ無い会社では、会計年度を開く案内が出ます。
4. 同じ期間をもう一度実行しても二重には計上しません（「計上する償却はありません」）。実行の後に登録した資産があれば、その資産だけの実行がもう 1 件できます。

実行できないときは理由が表示されます: 締め済みの期間・年度、まだ始まっていない期間、償却率表が未照合で会社の照合記録が無い、後の年度に償却を計上済みの資産がある、1 回 500 件を超える。

実行を取り消すときは、その実行（「償却の実行」の一覧の番号）を開いて「取消」します。逆仕訳ができ、次の実行で再計算されます。後の期間に同じ資産の実行があるときは新しい順に取り消す必要があり、除却・売却済みの資産を含む実行は先に除却・売却を取り消します。訂正日は実行の会計年度の中に限ります。

## 除却・売却

「会計・資金」の「除却・売却」で「新規」を押し、資産・日付・区分（除却 / 売却）を入れます。売却では売却価額（税抜）、税区分（既定は標準税率）、売却代金の科目（既定は 1910 未収入金）、必要なら売却先を入れます。下書きを保存すると、当年償却・除却時の償却累計・帳簿価額・消費税・売却益 / 損が計算されて表示されます。

「確定」を押すと、除却日の日付で次の仕訳が 1 本できます: 当年償却（その年度の期首から除却月までの月割。法令の限度額で、月ごとの配分の合計とは違うことがあります）、累計額の取り崩し、資産の取り崩し、除却損（または売却代金・仮受消費税・売却益 / 売却損）。資産の状態は「除却・売却済み」になり、以後の償却から外れます。取消すると逆仕訳になり、資産は使用中に戻ります。

**売却の消費税**: 売却価額は課税売上として消費税集計表の売上の行に載ります（売却益の科目に「税区分付きの貸方 = 売却価額」と「税区分なしの借方」の対を置く形）。この対の借方に税区分が無いため、売却のあった年度は申告準備で `tax_category_missing` の注意が出ます（既知。開発中の課題 Q8）。

## 減価償却明細表

「分析・レポート」の「減価償却明細表」（または「固定資産」メニュー）で会計年度を選んで実行します。資産ごとに取得価額・期首帳簿価額・当期増加（年度中の取得）・当期償却・当期減少（除却・売却時の帳簿価額）・期末帳簿価額・期末償却累計と合計が出ます。資産の種類・償却方法・状態は表示の言語で出ます。CSV で保存できます（経理・管理者のみ。出力した人の表示の言語）。10,000 行を超えると先頭 10,000 行だけを表示し、表題にその旨が出ます（合計は全件）。

## 償却資産申告の集計

「分析・レポート」の「償却資産申告の集計」で年（賦課期日の年、例: 2027）を入れて実行します。申告の種類が「対象外」でない資産を所在市区町村 × 種類（「2 機械及び装置」「6 工具、器具及び備品」など）で、前年前に取得したもの・前年中に減少したもの・前年中に取得したもの・計（1 月 1 日現在）の取得価額と件数に集計します。市区町村が空の資産は「（未設定）」（英語表示では「(not set)」）の行にまとまります。申告書に転記する集計は日本語の表示で出力してください。市区町村ごとの申告書の種類別明細に転記するための集計で、評価額・税額は出しません。

## 受信箱

前月までの最後の期間に未実行の償却がある資産の件数（「償却が未実行の資産」）と、下書きの除却・売却の件数が受信箱に出ます（経理・管理者）。
