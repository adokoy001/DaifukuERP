## はじめに

### 大福帳とは

大福帳（だいふくちょう、英語名 Daifuku）は、小さな事業者の「帳簿を中心にした業務」を一つのシステムで扱うために作っている業務システムです。取引先や品目の登録、売上と仕入の請求書、入金と支払の消込、仕訳と試算表、消費税の集計、在庫、継続契約（家賃など）を扱えます。名前は、江戸時代の商家が使っていた元帳に由来します。

特徴は三つあります。一つ目は、画面（ブラウザ）で行う操作と、プログラムや AI（MCP という仕組み）から行う操作が、同じ「アクション」を通ることです。二つ目は、確定した伝票を消したり書き換えたりできず、訂正は「取消」と「訂正版の作成」で行うことです。操作はすべて監査ログに残ります。三つ目は、業種ごとの違いを「導入テンプレート（pack）」として後から足せることで、v0.1 の小売・不動産賃貸に加え、2026-09-12に電器店・農家・飲食店チェーンの初版を追加しました。

### この文書の位置づけ（必ずお読みください）

大福帳は **実験段階のソフトウェア** です。AI を使った業務システム開発の実験として作られており、製品として販売・保守されているものではありません。

- **税務申告の正しさは保証しません。** 消費税の集計表や試算表は、申告の下ごしらえの参考資料です。申告書の作成は会計ソフトや税理士に依頼してください。
- 法令への適合（インボイス制度、電子帳簿保存法など）は、開発資料に出典を付けて実装していますが、第三者の確認や認証は受けていません。
- 利用者管理と導入時のバックアップ・実復元手順は追加済みです。SSO/MFAと確認メールは設定後に利用できます。外部provider実接続、監視、導入先の業務審査は別途必要です。[現在の範囲](10-limitations.md) を確認してください。

### この文書の読み方

画面に表示される文字は「 」で囲んで書きます（例: 「確定」ボタン）。手順は番号付きで書きます。

各章の最後に **検証** 欄があります。「2026-09-11 実機で確認」とある操作は、この文書を書いた時点で動いているシステムに対して実際に行い、結果を確かめたものです。「未検証」「文書から記述」とあるものは、開発資料（仕様書・作業記録）を読んで書いたもので、実際には試していません。

旧UIのスクリーンショットは 2026-09-11 に開発用のデモ環境で撮影しました。当時のデモ環境には小売と不動産の **両方のテンプレートを適用** していたため、次のように本来と違う名前で表示されている箇所があります。現在の会社別のメニュー・呼び名は、その会社に適用したテンプレートに従います。

- 「売上請求書」の画面の見出しが「家賃請求書」になっている（不動産テンプレートの呼び名）
- 「取引先」の画面の見出しが「入居者/取引先」になっている

また、デモ環境には複数の台本（練習用の取引データ）と自動テストのデータが同居しているので、画面の金額は付録 B の台本の数字とは一致しないことがあります。
