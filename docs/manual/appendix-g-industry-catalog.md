# 付録G：15業界の入口と追加10業界の操作台本

[業界の選定根拠と範囲](../domain/industry-catalog.md) / [履行案件の仕様](../specs/industry-catalog.md)

## どこから始めるか

「業界テンプレート」画面で対象会社を選び、業種名または業務内容で検索します。管理者が「サンプルデータも追加する」にチェックして「この会社に導入」を実行すると、その会社にだけ固有のメニュー・設定・品目・下書きが追加されます。保存済みの設定は維持されます。パックの再適用をしても、利用者が編集・開始・完了した案件の状態を戻しません。

既存の小売・不動産・電器店・農家・飲食チェーンを含め15業界です。`example` は拡張実装の例で、業界数には含みません。業界カードには対応範囲の説明があり、検索や「利用中」「未導入」で絞れます。利用できるカードはサーバが読み込んだパックに限られます。

追加10業界は「受付 → 開始 → 業界の実績・証跡を記録 → 完了 → 請求 → 入金」という流れです。一案件・一品目・一回の完了と請求を扱います。各業界の `案件を開始`、`履行を完了`、`案件から請求`、`履行実績` が専用メニューに表示されます。営業権限は案件の処理、経理権限は案件閲覧と既存の入金業務を担当できます。店舗限定担当・従業員ポータルの権限だけでこれらを閲覧・操作することはできません。

## 共通の演習手順

以下の日付と金額は架空の演習です。サンプルの受付日は導入時の日付、完了予定日は2日後です。例として受付日を2026-09-12とし、完了日2026-09-14、請求日2026-09-15、入金日2026-09-16を用います。別の日に練習する場合は受付日以降に読み替え、会計年度・税率・倉庫の設定がある日付で実行します。完了日は業務上の確定日を明示入力する欄です。

1. 業界の案件一覧から「サンプル」と付いた下書きを開きます。請求先、品目、税抜単価、受注数量、確認した税区分を見ます。実業務の税区分は契約ごとに判断し、サンプルの課税区分をそのまま実データに使わないでください。
2. 「案件を開始」で対象案件を選びます。受付・仕様・同意など、その業界で開始に必要な情報が足りなければ開始できません。
3. 案件の編集画面で、以下の表の「完了前に保存する実績・証跡」を追記します。証跡の欄は既存書類・相手方確認の参照番号です。資料そのものの真正性をシステムが認定するものではありません。
4. 「履行を完了」で案件、完了日、実績数量、履行・完了報告を入力します。案件固有の数量・証跡を確認して確定され、以降の直接修正・削除はできなくなります。汎用の「確定」でも同じ完了条件を検査します。
5. 「案件から請求」で案件と請求日を指定します。完了数量×税抜単価の請求明細が作られ、既存の税計算・仕訳を伴って確定します。同じ案件から再実行すると同じ請求書を返し、二重請求しません。請求日は完了日以降、期日は `<pack>.due_days` 日後です。
6. 案件の「発行した請求書」を開き、請求総額を確認します。「入出金」で方向を入金、同じ請求先、実際の入金日・金額・方法を設定し、消込明細にその売上請求書と金額を指定して確定します。
7. 「履行実績」で完了期間の開始・終了と取消判定の基準日を指定します。期間の終了日は基準日以前にします。案件番号から根拠の確定案件を開けます。

## 取消と実績の読み方

入金が残る案件は取り消せません。必要に応じて既存の入金を正規の取消操作で戻し、案件の取消に有効日を指定します。例では9/20に入金を取消し、その後9/20を指定して案件を取消します。案件の取消はその日付を請求取消に伝え、仕訳・連動在庫も既存の訂正処理で戻します。請求日より前の案件取消や、締め期間に違反する取消は拒否されます。生成した請求書だけを直接取り消す操作も、確定案件からの依存があるため拒否されます。

取消後にやり直す場合は案件を改訂します。新しい下書きには生成請求の参照・開始日時・取消日・状態を引き継がず、元伝票は保存します。元入力を確認・修正し、開始からやり直してください。

「履行実績」は完了日が対象期間内の確定案件を集計します。下書きは除外し、取消有効日が基準日以前の案件も除外します。9/14完了・9/20取消の案件は、基準日9/19では含み、基準日9/20では含みません。ここで示す数量・履行金額（税計算前・未丸め）は、未請求の完了案件を含みます。会計売上・利益・請求残高・入金残高の指標ではありません。請求や入金の残高は既存の債権レポートで確認します。CSVも同じ権限・会社のサーバ集計を使います。

数量の合計は同一パックの固定単位だけです。時間と人数、加工個数と泊数を混ぜた全業種合計を作りません。対象がレポート上限を超えた場合は期間を狭めるよう表示し、途中までの合計を正しい値として返しません。

## 初版の範囲

医療の診断・検査結果・患者記録・レセプト、介護保険請求・ケアプラン、製造BOM・原価、建設の出来高会計、物流配車、宿泊・美容の予約枠競合、学生の成績管理、専門サービスの工数原価は対象外です。業務固有の実績を共通会計へつなぐ最初の入口として使います。勤怠・給与は別の従業員機能であり、案件の履行時間から給与を自動算定しません。
