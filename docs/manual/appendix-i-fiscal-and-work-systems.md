# 付録 I 給与税保険・年末調整・勤務制度

この章は2026-09-13の制度版管理に対応しています。従来の [勤怠・申請・外部確認控除](appendix-f-workforce.md) に、対象制度の自動算定と、会社ごとの制度資料の導入・版確認を追加しています。[給与の受入仕様](../specs/enterprise-payroll.md)、[制度版管理の仕様](../specs/payroll-rule-versions.md)、[制度の一次資料](../domain/japan-payroll-automation.md) を適用条件の正本にしてください。配布する法定資料は引き続き2026年分だけです。

## 担当と画面

| 担当             | 画面                   | 操作                                                         |
| ---------------- | ---------------------- | ------------------------------------------------------------ |
| 従業員本人       | 自分の勤怠・申請 `/me` | 年調申告、扶養/保険/前職等の資料、差戻し対応、自分の確定結果 |
| 給与本部         | `/workforce/payroll`   | 制度資料、税保険条件、月次自動算定、支払証跡、申告受理と年調 |
| 勤務制度の管理者 | `/workforce/systems`   | 社員別の事前所定、合意根拠、期間確定/取消                    |
| 拠点・店長       | 既存の `/workforce`    | 担当拠点の勤怠等。給与税保険条件は給与権限なしでは開示しない |

本人が自分の給与/年調を承認する操作はできません。会社・本人の切替や権限失効では機微な資料を画面から撤去します。

## 制度の版と対応期間を確認する

本部では「税年」を選び、「制度の版と出典」でその年の資料を確認します。初期税年は、会社に導入された対応年と保存済みの実績から選ばれます。選択した税年は年末調整の対象年であり、「給与対象月」「給与支払日」「保険対象月」とは別の項目です。

| 状態             | 意味                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 未導入           | アプリに収録された資料ですが、この会社の自動計算にはまだ利用できません                         |
| 既存の制度資料   | 以前の機能で登録した2026年の資料です。既存の計算を継続でき、確認後に版の導入記録を追加できます |
| 導入済み         | この会社で資料・期間・方式を確認して導入した版です                                             |
| 後継版へ移行済み | 新規算定に使用する後継版があります。過去の計算に保存した版と結果は保持されます                 |

1. 「制度の詳細・導入」を開き、制度版、税年、資料確認日、国・通貨、計算方式、対応期間を確認します。
2. 「公式の出典を確認」から一次資料を開き、この会社の加入区分・適用条件と照合します。「内容の識別情報」は資料と版情報のhashを示します。hashは内容の同一性を確認する値で、行政機関の認証を示すものではありません。
3. 導入に伴う説明と確認対象の下書きを読み、「導入の確認記録」を入力して確認欄にチェックします。
4. 「確認した制度版をこの会社に導入」で登録します。同じ版の再導入は重複を作りません。確認中に内容が変わった場合は最新の資料を開き直します。通信失敗では入力を保持して再試行できます。

導入は選択中の会社だけに適用されます。既存の制度資料・確定給与・年末調整を上書きしたり、導入操作で過去の金額を再計算したりしません。旧形式の資料は保持し、新しい導入記録を追加します。後継版によって下書きの再算定が必要な場合は、確定時に説明されます。

制度一覧を取得できない場合は、制度欄にエラーを表示して新しい自動算定と導入を止めます。保存済みの給与・年調は引き続き閲覧できます。「最新の状態を確認」で資料の取得を再試行してください。

表示する期間は**この制度版の対応範囲**です。制度の法的な失効日とは限りません。2026年分では、健康・介護保険は3月分、子ども・子育て支援金は4月分から新しい率を使用し、雇用保険は賃金締日によって年度を判定します。支払日だけからすべての保険料率を選ぶものではありません。

## 月次給与を自動算定する

1. 給与本部画面で税年と「制度の版と出典」を確認し、上記の手順で対象の会社へ制度版を導入します。未導入・未収録の年度を他の年の表で代用しません。
2. 従業員を選び、「税・保険の条件」で適用期間、生年月日、居住者・月額甲欄/扶養申告、扶養数、協会けんぽ支部、加入/非加入/免除、標準報酬決定通知、雇用区分、住民税の通知額と確認根拠を保存します。給与実額から標準報酬を推定しません。非加入や0円も原資料の確認が必要です。
3. 条件が変わる場合は「将来の条件へ切替」を使い、元条件の終了日と新しい条件の開始日を分けます。確定給与で使った日を変える切替はできません。
4. 勤怠の承認と賃金条件を確認し、「給与の算定」で対象月・社員を選び「選択した従業員の税・保険込みで算定」を開きます。使用する制度版を確認し、支払日、保険対象月、課税/非課税手当等を原資料に合わせます。日付の初期値は編集できます。支払日は対象月末以降の通常支給日、保険対象月は支払月かその前月を指定します。制度の対応期間外では算定できません。
5. 支給・控除・差引額と根拠を確認して確定します。確定直前に本人条件・資料版・勤怠を再検査し、更新された下書きは再算定を求めます。確定後は本人に明細を公開し、訂正は理由付き取消と再計算で記録します。

従来の外部確認控除方式は残ります。外部確認額を入力した給与を、この機能で税保険自動算定した給与と表示しません。年調に利用する確定給与には支払証跡が必要で、従来方式の分は「支払の証跡」から支払日・課税支給・社会保険・徴収税額と根拠を確認して登録します。自動方式の証跡は計算資料に基づき扱います。

対象は国内居住者・JPYの定期給与、2026年月額甲欄（電算機特例）、一般の協会けんぽ/厚生年金/雇用保険の被保険者負担です。賞与、日額/乙欄、退職金、非居住者、複数事業所按分、独自健保料率、遡及控除等は対象外です。住民税賦課、社会保険の資格決定や届出は実行しません。

給与対象月は勤怠の所属期間です。たとえば12月勤務分を規程どおり翌年1月に支給する給与は、通常、翌年の給与所得として扱います。年末調整の帰属は契約・慣習による支給日等の確認が必要で、遅延した振込日だけから一般化できません。未払・遅延払や遡及差額の処理は、この通常給与の対応を広げて解釈しないでください。保存済みの給与・年調では「計算時に保存した制度版」から当時の資料を確認できます。

## 年末調整の申告・確認・精算

1. 本人は `/me` の「年末調整」で税年を確認し、扶養/配偶者、所得、保険料証明、住宅控除の確認額、前職源泉徴収票、無支払月等の資料を入力して提出します。会社に制度資料がない年は申告を開始できず、給与担当への案内を表示します。一般従業員は制度を導入できません。個別事情の適格性は原資料で確認してください。
2. 給与本部は「年末調整」から申告と証明を確認し、受理または理由付き差戻しを行います。本人の自己受理はできません。
3. 年間の給与支払/税証跡・前職資料・無支払月が揃ったことを確認し、年末調整を計算します。現2026年版は2026年12月の通常年調と翌年1月の再調整を扱い、実施日を制度の対応期間内かつ今日以前に制限します。翌年1月に2026年分を再調整することは、2027年月次給与に対応する意味ではありません。再調整は源泉徴収票の交付状況等も確認してください。画面の期間上限だけで再調整の実務要件を満たすとは扱いません。
4. 給与所得・各控除・年税・徴収済税と、還付/追加徴収額を確認して確定します。未確定給与や未登録証跡を黙って除外しません。確定年調で使った給与・申告は先に変更/取消できません。
5. 実際の還付・追加徴収を別の銀行/給与手順で実施した後、精算日と参照番号を記録します。記録操作で銀行送金を実行したとは扱いません。

給与2,000万円超などの対象外、非居住者・災害減免・年途中死亡/海外転出等は別手続きです。住宅控除の適格性を借入額から推定せず確認済みの控除額を用います。月次税表と12月の年調改正後控除を混同しません。e-Tax/eLTAX送信、法定帳票の電子申告、銀行送信は含めません。

## 勤務制度を開始前に確定する

1. `/workforce/systems` で将来の開始月と従業員を選び、「選択した従業員の制度を作成」を開きます。
2. 通常、1か月変形、フレックスのいずれかを選びます。暦月の期間、日別所定/休日、標準日時間、総労働時間、合意資料と確認記録を登録します。フレックスは1〜3暦月で、本人の始終業選択と必要な合意/届出確認も入力します。
3. 所定カレンダー、期間総枠、重複期間を確認し「開始前に確定」を実行します。開始後の所定書換え、確定給与や公開シフトの基準を壊す変更は拒否します。
4. シフト推薦と給与算定では確定勤務制度・事前所定・期間残枠を使います。フレックスの推薦案は本人の始終業選択を置き換える指示ではありません。

1か月変形は日→週→期間の超過を重複させず算定します。複数月フレックスは各月の週平均50時間超と最終清算の40時間平均超を二重に数えません。法定休日と深夜は区別します。時間不足の賃金控除・翌期繰越を自動推定しません。

1年変形、1週間非定型、44時間特例、裁量/みなし、高度プロ、期間途中の入退社・制度移行、任意締日、日をまたぐ勤務の給与自動算定は対象外です。合意・届出済みや個別の法令適合はシステムだけで証明しません。

この操作手順は2026-09-13の仕様・UI・業務actionを読んで整理しています。税表/料率境界の純関数、制度版と旧証跡の互換・権限・競合のDB試験、通常/変形/フレックスとUIの統合結果は [現在地](../STATUS.md) と作業記録を確認してください。実際の給与支払、行政・銀行送信、導入先の資格/控除適格性を検証したものではありません。
