# 付録 N 業務分野から画面を探す

ホームと左メニューを、業務分野ごとの入口に整理しました。既存の台帳・伝票・専用画面のURLは変わりません。古い章の画像にあるmodule別メニューや「すべてのエンティティ」は、新しい「すべての画面を探す」から開けます。

2026-10-29 に、キーボードで画面を開く「画面と記録を開く」（コマンドパレット）、最近開いた記録、お気に入り、画面ごとの「この画面の説明」を追加しました（[下記](#画面と記録をすばやく開く2026-10-29-追補)）。

## 最初に業務分野を選ぶ

ホームのカード、または左メニューの業務分野を選びます。利用できる画面がない分野は表示されません。カードの「画面」数は入口の数で、伝票や取引先の記録件数ではありません。

| 業務分野 | 主な画面 |
| --- | --- |
| 販売・仕入 | 商流・受発注、取引先、売上・仕入の請求、契約 |
| 在庫・商品 | 商品・単位・倉庫、入出庫、棚卸 |
| 人事・労務 | 従業員・勤怠、シフト、給与・税保険、勤務制度 |
| 会計・資金 | 仕訳、入出金、銀行連携、月次締め、連結、FC精算、申告準備 |
| 店舗・連携 | チェーン運営、業界別業務、POS、店舗機器 |
| 分析・レポート | レポートセンター、ピボット分析、各業務の帳票 |
| 設定・管理 | 会社設定、利用者と権限、業界テンプレート、自分のアカウント |
| その他 | やること（受信箱）、分類されていない追加moduleの画面 |

分野の入口では、目的別の専用画面カードと、その分野のマスター・記録などを選べます。「銀行連携・消込」のような専用画面へ入ってから、そこで扱う作業を進めます。商品や取引先のようなマスターは一覧を開き、既存の記録確認・新規作成を行います。

個別の帳票は「分析・レポート」にまとめています。例えば試算表は「分析・レポート」から探すか、「すべての画面を探す」で「試算表」と検索します。画面を開いた後の期間入力、実行、CSV、ピボット操作は [付録M](appendix-m-analytics.md) のとおりです。

## 名前で画面を探す

1. 左メニューの「すべての画面を探す」を開きます。
2. 「請求」「給与」「銀行」など、開きたい画面の名前を入力します。日本語・英語の画面名、別名、説明、module名やURLから探せます。
3. 必要なら「画面の種類」で、業務画面、マスター・記録、帳票、操作、設定を選びます。一覧は24画面ずつ表示し、先頭・前へ・ページ選択・次へ・最後で移動できます。

分野の入口に条件を指定していない場合、専用画面は上部の「よく使う操作」にまとめ、下の一覧では重複して表示しません。検索や種類の条件を指定すると、専用画面も含めて一致する画面を一覧にまとめます。

全角・半角、大文字・小文字、カタカナ・ひらがなの違いを吸収して検索します。空白で複数の語を区切ると、すべての語が含まれる画面を探します。該当しなければ語を減らすか、種類の絞り込みを解除してください。

ここで検索するのは画面の入口です。取引先名や伝票番号など実際の記録を探す場合は、該当する一覧画面を開いて、その一覧の検索欄を使います。伝票の明細は親の伝票内で操作するため、独立した入口には表示されません。

## 現在位置と戻り先

画面上部のパンくずで現在位置を確認できます。例は「ホーム → 販売・仕入 → 売上請求書 → 新規作成」です。前の項目を選ぶと一覧や業務分野へ戻り、最後の項目が現在の画面を表します。詳細画面のURLを直接開いた場合も、その画面の上位へ戻れます。検索の条件・種類・ページはURLに含まれるため、一覧から画面を開いた後にブラウザの「戻る」で戻ると復元されます。

「自分のアカウント」は従来の独立した画面です。画面内の「ワークスペースへ戻る」からホームへ戻れます。

入力画面に未保存の変更がある場合は、新しい入口やパンくずから移動する時も、既存の変更破棄確認が働きます。編集を続ける場合は移動を取り消し、必要な内容を保存してから移動してください。

## ホームで伝票の状況を確認する

ホームは業務分野を選ぶための入口です。伝票の下書き・確定・取消件数を確認する場合は「伝票の状況を確認」を開きます。最初は「販売」の状況を表示し、利用できない場合は別の業務を初期選択します。「状況を確認する業務」で切り替えると、その業務の伝票に絞って件数を取得します。ホームを開くだけで全moduleの伝票件数を読み込むことはありません（ホームを開いたときに取得するのは、次の「やること」の件数です）。

関連するマスターは先頭8件、レポートは先頭5件を近道として表示します。残りは「この分野の画面を見る」や「分析・レポートを開く」から探せます。

「自分の勤怠・申請」は利用できる従業員のメニューに残っています。上部の会社名から会社切替の画面を開けます。会社や権限の切り替え後は、選択中の会社で利用できる分野と画面が表示されます。

## やること（受信箱）で処理待ちを確認する

承認待ちの経費、照合待ちの銀行明細、確認待ちの日次報告など、自分が処理する仕事の件数を業務ごとに集めて表示します。伝票の状況（下書き・確定・取消の件数）とは別の機能です。

1. ホームの「やること」カードで、合計件数と急ぎの項目（警告の項目を先に、件数の多い順に最大5件）を確認します。急ぎの項目は件数の前に「急ぎ」と表示されます。項目を選ぶと、その仕事を処理する画面が開きます。
2. カードの「すべて見る」、サイドバーの分野「その他」、または「すべての画面を探す」で「やること」「受信箱」と検索して `/inbox` を開くと、すべての項目を業務ごとにまとめて表示します。受信箱を使える利用者には、それまで「その他」の分野が無かった場合でも、サイドバーに「その他」が表示されます。
3. 件数は画面を開いたときに取得します。開いたままの画面は自動では更新しません。最新にする場合は「最新の状態に更新」を押します。
4. ある業務の件数を取得できなかった場合は、その業務だけに「取得できませんでした」と、サーバーからのメッセージが表示されます。エラーコード・HTTP の状態・対処のヒントは「技術情報」を開くと確認できます。他の業務の件数はそのまま使えます。その業務の「再試行」を押すと、その業務だけを取得し直します。取得できると、その業務の見出しへ移動し、結果が読み上げられます。
5. 項目は返ってきたものの、開ける画面が利用者の権限に無い場合は「開ける画面がない項目が N 件あります」と表示されます。この場合は「処理待ちはありません」とは表示しません。管理者に権限を確認してください。

| 業務 | 表示される項目 | 開く画面 |
| --- | --- | --- |
| 従業員・労務 | 確認待ちの勤怠、承認待ちの勤怠訂正・有給申請・経費（拠点管理者・人事）、精算待ちの経費と確認待ちの給与（給与担当）、差し戻された自分の勤怠・経費 | 従業員・勤怠管理（最も古い申請の月）、自分の勤怠・申請（最も古い差戻しの月と、その勤怠または経費のタブ） |
| 入出金 | 支払期日を過ぎた未入金の売上請求・未払の仕入請求、請求に配分していない入出金 | 未消込請求書（帳票）、入出金の一覧（未配分額の多い順） |
| 銀行連携 | 照合待ちの銀行明細 | 銀行連携・消込 |
| 飲食店（チェーン） | 未提出の日次報告（直近7日の営業予定日、昨日まで）、差し戻された日次報告、店長確認待ち・本部確定待ちの日次報告 | チェーン運営（該当する期間） |
| 店舗機器連携 | 結果の確認が必要な機器処理（結果を確認して解決できる機器管理者のみ） | 店舗・機器連携 |
| 申告準備 | 別の担当者が作成した確認待ちの準備資料 | 申告準備 |

件数は各業務の権限と担当範囲（会社・拠点・店舗・本人）で数えます。拠点管理者には担当拠点の申請だけ、店舗の担当者には担当店舗の報告だけが数えられます。自分の申請や自分が作成した準備資料は、自分では承認・確認できないため件数に含めません。件数が0の項目は表示しません。表示できる業務が一つもない利用者には、ホームのカードも画面検索の入口も表示されません。

入出金の項目から開く画面は、数えた対象だけに絞られていません。未消込請求書の帳票では方向（入金または支払）を選んで実行し、支払期日の列で期日を過ぎた請求を確認します。入出金の一覧は下書き・取消済みも含めて未配分額の多い順に並ぶため、状態が確定済みの行を確認します。

受信箱から直接承認することはできません。項目から開いた専用画面で、従来どおり内容を確認して操作します。メールやブラウザへの通知、既読の管理、件数の推移はありません。従業員・勤怠管理は月単位で表示するため、前月以前の申請が複数の月にある場合は、開いた画面で表示する月を切り替えてください。

## スマートフォンとキーボード

小さな画面では上部のメニューボタンで左メニューを開きます。Tabキーでメニュー内の操作へ移動できます。Escapeまたは閉じるボタンで閉じると、開くためのボタンへフォーカスが戻ります。画面を選ぶとメニューが閉じ、新しい画面の本文へ移動します。キーボードで「本文へ移動」を使うと共通メニューを飛ばせます。言語切替・自分のアカウント・ログアウトはメニュー下部にあります。

## 表示されない画面

利用者の権限、選択した会社、適用済みテンプレートによって表示できる画面は異なります。検索対象にも利用できる入口だけが含まれます。想定した画面がない場合は、選択中の会社と権限を確認してください。表示だけで業務データの権限を変えるものではなく、直接URLを開いた場合や保存時にも従来の認可を行います。

個人別のメニュー編集（並べ替え・非表示）はありません。お気に入りと最近開いた記録は次の節のとおりブラウザ内に保存します。分析設定の保存はピボット専用の機能です。

## 画面と記録をすばやく開く（2026-10-29 追補）

### 画面と記録を開く（Ctrl+K）

1. `Ctrl` を押しながら `K` を押します（macOS は `⌘` + `K`）。画面上部の「検索」ボタンでも開けます。入力欄にいても開きます。確認のダイアログや、スマートフォンで開いた左メニューの上では開きません（先に閉じてください）。
2. 開きたい画面の名前や、最近開いた取引先名・伝票番号の一部を入力します。検索の規則は「すべての画面を探す」と同じです（全角・半角、カタカナ・ひらがなの違いを吸収し、空白区切りはすべての語を含むものを探します）。
3. 候補は「画面」（最大20件）、続いて「最近開いた記録」（最大10件）の順に出ます。`↑` `↓` で選び、`Enter` で開きます。クリックでも開けます。
4. `Esc` または右上の ×（閉じる）で閉じると、開く前に操作していた場所へ戻ります。

何も入力していないときは、お気に入り、最近開いた記録、主要な業務画面（業務分野ごとに 1 画面ずつ、8 画面まで）が出ます。画面の一覧を読み込んでいる間は「読み込み中…」と表示されます。候補が多いときや見つからないときは、下の「すべての画面を探す」から、入力した語で全画面の検索を開けます。権限のない画面は候補に出ません。入力中のフォームに未保存の変更があると、移動の前にいつもの破棄確認が出ます。

### 最近開いた記録

取引先・品目・伝票などの記録（詳細画面）を開くと、左メニューの「最近」に新しい順で5件まで表示されます。「画面と記録を開く」からは30件まで探せます。会社を切り替えると、その会社で開いた記録だけが表示されます。

- 保存するのは記録の種類、ID、名前（または伝票番号）、開いた日時だけで、記録の内容は保存しません。
- 従業員・給与などの記録は、名前を保存せず「従業員 1a2b3c4d…」のように種類と短いIDで表示します。
- その種類の記録を見る権限がなくなると表示されません。個別の記録が見られなくなった場合は、開いたときに通常の権限エラーになります。名前の項目が見えない権限に変わった場合は、名前を出さず種類と短いIDで表示します。
- ログアウトすると（全端末からのログアウトや、パスワード・認証設定の変更による再ログインを含む）、このブラウザに残る記録の名前を消します。次にログインしたときは、もう一度開くまで「取引先 1a2b3c4d…」のように表示されます。時間切れで自動的にログイン画面に戻った場合は消えません。

### お気に入り

よく使う画面（一覧・業務画面・帳票など）を開き、画面上部の現在位置の右にある「お気に入り」を押すと、左メニューの「お気に入り」に追加されます。もう一度押すと外れます。新規作成や詳細の画面にはボタンはありません（お気に入りは画面単位です）。20画面まで登録できます。権限がなくなった画面は表示されません。

「最近」と「お気に入り」は、1件もないときは見出しも表示されません。どちらも、同じブラウザの、同じ利用者・会社でだけ使えます（別のパソコンやブラウザには引き継がれません）。共用のパソコンでは、使い終わったら必ずログアウトしてください（記録の名前が消えます）。記録の種類とID、お気に入りの画面まで消すには、ブラウザのサイトデータを削除します。ブラウザの設定（プライベートモードなど）で保存できない場合は表示されませんが、ほかの操作はそのまま使えます。

### この画面の説明

画面上部の現在位置の右にある「この画面の説明」を押すと、その画面を説明しているマニュアルの章が新しいタブで開きます。説明の章がない画面には表示されません。マニュアルは日本語だけです（英語表示では「Help for this screen (Japanese)」と表示されます）。

リンク先は既定で公開リポジトリのマニュアルで、配布物（`scripts/build-release.mjs` で作ったもの）ではその配布物と同じ版の章を開きます。社内にマニュアルを置く場合は、配布物を作るときに `--manual-url` で章ファイル（`04-masters.md` など）を置いた場所のURLを指定します。Web を直接構築する場合は `VITE_MANUAL_URL` で指定します（いずれも技術者向け。[配備手順](../operations/deployment.md#1-配布物を作る)）。

### スマートフォン

390px 程度の幅では、上部の虫眼鏡のボタンで「画面と記録を開く」が画面の幅いっぱいに開きます。「最近」と「お気に入り」は左メニューを開くと業務分野の下にあります。
