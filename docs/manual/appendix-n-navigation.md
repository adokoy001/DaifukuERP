# 付録 N 業務分野から画面を探す

ホームと左メニューを、業務分野ごとの入口に整理しました。既存の台帳・伝票・専用画面のURLは変わりません。古い章の画像にあるmodule別メニューや「すべてのエンティティ」は、新しい「すべての画面を探す」から開けます。

## 最初に業務分野を選ぶ

ホームのカード、または左メニューの業務分野を選びます。利用できる画面がない分野は表示されません。カードの「画面」数は入口の数で、伝票や取引先の記録件数ではありません。

| 業務分野 | 主な画面 |
| --- | --- |
| 販売・仕入 | 商流・受発注、取引先、売上・仕入の請求、契約 |
| 在庫・商品 | 商品・単位・倉庫、入出庫、棚卸 |
| 人事・労務 | 従業員・勤怠、シフト、給与・税保険、勤務制度 |
| 会計・資金 | 仕訳、入出金、銀行連携、連結、FC精算、申告準備 |
| 店舗・連携 | チェーン運営、業界別業務、POS、店舗機器 |
| 分析・レポート | レポートセンター、ピボット分析、各業務の帳票 |
| 設定・管理 | 会社設定、利用者と権限、業界テンプレート、自分のアカウント |
| その他 | 分類されていない追加moduleの画面 |

分野の入口では、目的別の専用画面カードと、その分野のマスター・記録などを選べます。「銀行連携・消込」のような専用画面へ入ってから、そこで扱う作業を進めます。商品や取引先のようなマスターは一覧を開き、既存の記録確認・新規作成を行います。

個別の帳票は「分析・レポート」にまとめています。例えば試算表は「分析・レポート」から探すか、「すべての画面を探す」で「試算表」と検索します。画面を開いた後の期間入力、実行、CSV、ピボット操作は [付録M](appendix-m-analytics.md) のとおりです。

## 名前で画面を探す

1. 左メニューの「すべての画面を探す」を開きます。
2. 「請求」「給与」「銀行」など、開きたい画面の名前を入力します。日本語・英語の画面名、別名、説明、module名やURLから探せます。
3. 必要なら「画面の種類」で、業務画面、マスター・記録、帳票、操作、設定を選びます。一覧は24画面ずつ表示し、先頭・前へ・ページ選択・次へ・最後で移動できます。

分野の入口に条件を指定していない場合、専用画面は上部の「よく使う操作」にまとめ、下の一覧では重複して表示しません。検索や種類の条件を指定すると、専用画面も含めて一致する画面を一覧にまとめます。

全角・半角、大文字・小文字、カタカナ・ひらがなの違いを吸収して検索します。空白で複数の語を区切ると、すべての語が含まれる画面を探します。該当しなければ語を減らすか、種類の絞り込みを解除してください。

ここで検索するのは画面の入口です。取引先名や伝票番号など実際の記録を探す場合は、該当する一覧画面を開いて、その一覧の検索欄を使います。伝票の明細は親の伝票内で操作するため、独立した入口には表示されません。

## 現在位置と戻り先

画面上部のパンくずで現在位置を確認できます。例は「ホーム → 販売・仕入 → 売上請求書 → 新規作成」です。前の項目を選ぶと一覧や業務分野へ戻り、最後の項目が現在の画面を表します。詳細画面のURLを直接開いた場合も、その画面の上位へ戻れます。検索の条件・種類・ページはURLに含まれるため、一覧から画面を開いた後にブラウザの「戻る」で戻ると復元されます。

「自分のアカウント」は従来の独立した画面です。画面内の「ワークスペースへ戻る」からホームへ戻れます。

入力画面に未保存の変更がある場合は、新しい入口やパンくずから移動する時も、既存の変更破棄確認が働きます。編集を続ける場合は移動を取り消し、必要な内容を保存してから移動してください。

## ホームで伝票の状況を確認する

ホームは業務分野を選ぶための入口です。伝票の下書き・確定・取消件数を確認する場合は「伝票の状況を確認」を開きます。最初は「販売」の状況を表示し、利用できない場合は別の業務を初期選択します。「状況を確認する業務」で切り替えると、その業務の伝票に絞って件数を取得します。ホームを開くだけで全moduleの件数を読み込むことはありません。

関連するマスターは先頭8件、レポートは先頭5件を近道として表示します。残りは「この分野の画面を見る」や「分析・レポートを開く」から探せます。

「自分の勤怠・申請」は利用できる従業員のメニューに残っています。上部の会社名から会社切替の画面を開けます。会社や権限の切り替え後は、選択中の会社で利用できる分野と画面が表示されます。

## スマートフォンとキーボード

小さな画面では上部のメニューボタンで左メニューを開きます。Tabキーでメニュー内の操作へ移動できます。Escapeまたは閉じるボタンで閉じると、開くためのボタンへフォーカスが戻ります。画面を選ぶとメニューが閉じ、新しい画面の本文へ移動します。キーボードで「本文へ移動」を使うと共通メニューを飛ばせます。言語切替・自分のアカウント・ログアウトはメニュー下部にあります。

## 表示されない画面

利用者の権限、選択した会社、適用済みテンプレートによって表示できる画面は異なります。検索対象にも利用できる入口だけが含まれます。想定した画面がない場合は、選択中の会社と権限を確認してください。表示だけで業務データの権限を変えるものではなく、直接URLを開いた場合や保存時にも従来の認可を行います。

今回の入口には、お気に入り・最近使った画面・個人別のメニュー編集や保存はありません。分析設定の保存はピボット専用の機能です。
