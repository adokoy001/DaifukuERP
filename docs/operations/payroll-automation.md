# 税・保険の自動給与と勤務制度の運用

制度の対象と根拠は [給与仕様](../specs/enterprise-payroll.md) と [一次資料](../domain/japan-payroll-automation.md) を参照する。

## 準備する順序

1. 人事本部で社員・在籍日・拠点を登録する。給与本部で期間の重複しない賃金条件を確認する。
2. 変形/フレックスを使う場合、店舗管理者または人事本部が「勤務制度」で清算期間・全日所定・法定休日・協定と合意を登録し、開始前に確定する。フレックスは本人の始終業選択を確認し、1か月超なら届出の確認も必要。シフトはこの確定後に公開する。
3. 給与本部が「税・保険と年末調整」で2026制度資料を準備する。社員の扶養等申告、資格/免除、協会けんぽ支部と標準報酬、年金等級、雇用保険の業種区分、住民税通知を期間付きで登録する。
4. 扶養・等級等が将来変更されるときは「将来条件へ切替」を使う。過去の給与を変更せず、旧条件を新開始日前日までと新条件に分ける。既に新開始日以降の給与に使われた条件は切替できない。

## 月次給与

実際の打刻・休憩・有給・訂正を承認し、月末後に計算する。税/保険の支払日・保険対象月・課税/非課税手当・その他控除を入力する。保険対象月は支払月または前月。雇用保険は月末締切日で年度を選ぶ。3月給与を4月に支払う場合でも、雇用保険を新料率へ早めない。

自動計算後に表示された控除・手当・差引額と根拠を確認し、既存の給与確定操作で明細を公開する。本人条件や勤怠が変更された場合は再計算する。金額だけを直接差し替えて自動給与として確定することはできない。

従来の外部確認給与も継続できる。その給与を年末調整に含めるには、確定後に支払日・課税支給額・原資料の証跡を登録する。所得税・社会保険は元給与の確定控除から取得する。翌年1月支払の証跡は支払年の判別に使い、2026年集計へ混ぜない。

## 年末調整

従業員は自分の申告を提出する。保険料は給与天引き社会保険を重複入力せず、証明書の区分別適格支払額を記載する。親族の「本人が控除を申告する」を外すと扶養・特定親族・障害控除をこの人へ二重計上しない。子の生命保険特例・所得金額調整は、対象なら他の親が扶養控除を受ける場合も適用される。

給与本部は本人申告・前職源泉徴収票・証明資料・無支払月の理由を確認して受付する。12月の給与支払を含む年間資料が揃ったら、最後の年内支払日以降の調整日で計算する。元資料が変われば再受付/再計算が必要。確定すると本人に還付/追加徴収と根拠が見える。

未精算の結果を訂正する場合は年末調整を理由付きで取り消し、資料を訂正して再計算・再確定する。実際に返金/追加徴収したら精算日と銀行等の参照を記録する。この記録から送金は実行しない。精算済み結果の取消・逆送金・翌年の自動税率は対象外。

## 勤務制度の見方

通常制は従来の1日/週の保護基準。1か月変形は事前に定めた日・週の所定と期間の法定総枠を順に検査し、重複する時間外を除く。フレックスは各月を清算し、複数月なら50時間平均を超えた既払時間外を最終期間40時間平均の超過から除く。清算最終月には、所定を超えたが時間外にならない時間の通常賃金も加える。法定休日と深夜割増は別に保持する。

推薦シフトの個人条件上限を増やしても、通常勤務の法定基準を増やしたことにはならない。勤務制度が確定した日の所定・休日・他週公開済時間に基づいて、割当可能な範囲を決める。フレックス案で本人の始終業の選択を強制しない。清算期間途中の入退社・賃金変更、日跨ぎ給与、1年変形等は仕様の対象外一覧で確認する。
