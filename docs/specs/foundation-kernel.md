# 共通基盤の不変条件（ADR-0016）

状態: approved（2026-09-12 ユーザーの基盤強化・レビュー不具合修正指示）

## 受入条件

1. Repository は全書込みで参照先の tenant/company 一致を検証し、会社文脈の所属も検証する。
2. serverOwned 項目の公開入力を拒否する。モジュール内の不透明capabilityは項目所有のみを追加し、既存の操作・行権限を変更しない。UIメタデータへ所有・既定値を公開する。
3. 更新・削除・状態遷移・子明細の変更は同じ親行をロックし、expectedVersion を明細のみの更新でも検証する。500件超の明細は全入口で拒否する。
4. マスク項目は通常読取だけでなく監査・where・並べ替え・集計でも保護する。空ORはfalseとする。
5. 名前付き確定遷移の役割・guardを通常submitから迂回できない。取消→下書きへの直接遷移は拒否する。
6. outboxはSKIP LOCKEDでclaimし、イベントの会社文脈で配信する。handler失敗時のDB変更をsavepointで取消し、試行回数だけ記録する。
7. DB numeric(20,6)へ保存できない精度・桁数を保存前に拒否し、tenant scopeの出力schemaを一致させる。
8. テナントを指定したログインを可能にし、初期化の冪等性はテナントを識別して判定する。
9. 未適用packのext必須検証・既定値hook・ラベル・イベント購読は別会社のcore操作へ影響しない。pack専用entity/actionも適用前は拒否し、applyPackのseed/sampleだけ同一transaction内で適用状態を持つ。保存済み設定は明示force以外では維持する。

## 検証

意味のある回帰試験をkernelの独立DBで実行し、既存unit/dbを確認する。rootが全体gateを実行する。移行とアプリ経路・業務不変条件は各担当と統合する。

## 範囲外

全業界の業務追加、任意通貨・複数会社役割モデル、外部副作用のexactly-once保証、既存DBの自動データ修復。
