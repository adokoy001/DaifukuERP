# 国内給与の自動控除・年末調整・勤務制度

状態: 実装済み・統合受入済み（[検証記録](../log/2026-09-12-enterprise-operations.md)）。2026-09-12。親: [統合拡張](enterprise-operations.md)。制度根拠: [2026給与資料](../domain/japan-payroll-automation.md)。

2026-09-13の [制度版管理仕様](payroll-rule-versions.md) は、国別算定器・期間付きデータ・会社別導入と旧記録の互換を追加する。以下の2026年の業務範囲は維持し、年度の選択は導入済みデータで決める。制度値を持つ単体試験は `l10n/jp/test/payroll-calculation.test.ts` へ移動し、元の期待値を保持した。設計は [給与構造](../architecture/payroll-automation.md) と [ADR-0024](../adr/0024-payroll-rule-releases.md) を参照。

## 対象と入力の責任

日本居住者へ支払うJPYの定期給与、2026年の月額甲欄（電算機特例）、一般の協会けんぽ・厚生年金・雇用保険の被保険者負担を対象とする。保険の資格・免除・標準報酬決定通知・扶養申告・住民税通知は給与担当が期間と証憑を確認する。制度から計算できる税額/保険料/年税/控除額は自動算定し、入力資料が未確認なら計算/確定を拒否する。非加入や通知0円も明示した状態と根拠を必要とする。

勤務制度は週40時間の通常制、暦月の1か月変形、1〜3暦月のフレックス。変形の日別所定・週所定、フレックスの清算期間/総労働時間/標準日時間/自由な始終業選択/労使合意・届出確認を社員別の期間に記録し、開始前に確定する。勤務制度による月給の不足控除や賃金繰越を推定せず、過不足の時間と根拠を示す。休憩、深夜、法定休日と60時間超割増は既存制度を保つ。

## 受入基準

- AC1: 2026年の公式資料を初期化するとき、税表・料率・端数・支部・適用開始/終了・確認日・URLを保持する。適用年外/不足資料は0の計算にしない。2026月次税表と12月年調の改正後控除を分離する。
- AC2: 使用済み本人条件は過去の値を変更できない。将来変更は `supersede_payroll_condition` が使用済み支払日/保険月末/賃金締切日を検査し、旧条件の終期短縮と新条件追加を同じトランザクションで行う。給与担当が社員条件を保存するとき、会社権限・社員・期間重複・確認資料・expectedVersionを検査する。店長や他人には給与条件を開示しない。本人は公開済み自分の結果だけを参照する。
- AC3: 月次自動算定を要求したとき、承認勤怠・賃金・課税/非課税手当・保険月・支払日・月末賃金締切日・本人条件を使いDecimalで8控除と差引額を求める。標準報酬等級/年齢/料率改定境界、介護・子育て支援・雇用区分と端数を明示する。
- AC4: 自動控除給与を確定するとき、最新の資料と条件を再読取し、税額/控除や手当のすり替えを拒否する。計算根拠と入力を凍結し、取消は理由・版を要する。従来の外部確認給与を自動算定済みと表示しない。
- AC5: 本人が年末調整申告を提出したとき、申告・保険料証明・扶養/配偶者・前職給与等を版管理する。親族ごとの `claimDependentDeduction` で本申告者の扶養・特定親族・障害控除を選択し、夫婦双方に適用できる子の生命保険特例/所得金額調整とは分ける。給与担当の受理/差戻し、自己受理禁止、会社/本人分離を適用する。
- AC6: 年末調整を計算したとき、確定給与と税証跡、前職源泉徴収票を集計し、2026年調給与額、給与所得、基礎・扶養・配偶者・特定親族・障害・生命/地震/社会保険等控除、所得金額調整、住宅控除、年税と徴収済税との差額を自動計算する。証跡未登録・未確定の給与を黙って除外しない。2,000万円超等の対象外を拒否する。
- AC7: 年調を確定/取消/精算記録するとき、社員ロック・資料版・二重確定・状態を検査する。確定年調に使われた給与や申告資料を先に変更/取消できない。給与明細そのものを年調処理で上書きせず、還付/追加徴収と精算参照を別記録にする。銀行送金を実行したとは扱わない。
- AC8: 勤務期間を確定するとき、期間/日数/事前所定/合意/会社・社員スコープ/予定時間総枠を検査する。開始後の所定の書換えや確定実績の基準変更を拒否する。
- AC9: 勤怠から給与を計算するとき、1か月変形の日→週→期間超過を重複除外して集計する。フレックスは1か月なら清算総枠、複数月なら各月の週平均50時間超と最終清算の40時間平均超を二重算入せず算定する。法定休日は別枠、深夜加算は維持する。
- AC10: シフトを推薦/保存/公開するとき、社員別の確定勤務制度・事前所定・期間残枠をsnapshotへ含め、通常制の上限を全社員へ誤適用しない。フレックスの案は本人の始終業選択を置き換えない。勤務制度の変更・期間外の公開予定もsource版に反映する。

## 明示する境界

賞与/日額/乙欄/退職金/非居住者/複数事業所勤務の合算・保険者按分、健保組合独自料率、労災保険の年度更新、社会保険の資格決定/算定基礎・月変の自動届出、住民税賦課そのもの、e-Tax/eLTAX送信は初版に含めない。年調は2026年12月の通常の居住者の年調とし、年途中の死亡・海外転出時の旧控除/災害減免などの特殊処理は拒否する。本人の個別事情を未確認のまま控除適格としない。

1年変形、1週間非定型、44時間特例、裁量・みなし、高度プロ、任意の給与締日、日跨ぎ実績の給与、清算期間途中の入退社・制度移行、時間不足の翌期繰越/自動控除、清算期間途中の賃金単価変更、同一週に実勤務がある通常/変形とフレックスの切替、4週4休の例外は未対応。全労働法適合や36協定の届出済みをシステムだけで証明しない。

## 検証

一次資料の計算例・税表境界・1円/10円/100円/1000円端数、保険月3月/4月・年齢40/65・等級端点・扶養数・生命保険新旧と23歳未満特例・年調給与4,000円刻み/2,000万円上限を純粋関数で照合する。DBで権限、未確認拒否、資料変更後の確定拒否、確定/取消/精算と月次凍結、競合、開始後の所定変更拒否を実行する。通常・変形・複数月フレックスの同じ実績による相違とシフト期間残枠を回帰に含める。rootがUI・API/MCP・移行・全gateを統合検証する。


## 実装上の運用契約

- `fiscal-contract.ts` / `work-system-contract.ts` がREST/MCP/Web共通の入力・出力契約。新6 entity は共通DSLから生成し、任意CRUDでは状態を変更しない。
- 自動月次の給与支払日は2026年、給与月末から翌月まで。保険月は支払月/前月、雇用保険は支払日ではなく賃金締切日（この版は月末）の年度料率を使う。保険月を重複して自動控除しない。
- 年調は12月支払実績を含む受付済み申告から2026-12-01〜2027-01-31に実施する。未支払月は理由を申告して給与本部が受け付ける。給与月と支払年を分け、既存の外部確認給与は翌年1月支払の証跡も登録し、2026年集計から除外できる。翌年税率の自動計算とは異なる。
- 年調確定はその年の給与/申告の変更を凍結する。支払年未確定の従来給与についても、当該年またはその前年給与月の追加/取消を保守的に拒否する。未精算なら理由付き年調取消→資料訂正→再計算/再確定。精算済みの取消・銀行返金の逆処理は対象外。
- 勤務制度はシフト公開前に確定する。開始後は取消不可、開始前でも公開割当が依存する間は取消不可。本人の年調・勤務制度は現在の社員所属を親スコープにして、異動後も本人行制約を維持する。
- 日別所定は整数分、実勤怠は整数ミリ秒。期間法定総枠の端数はBigIntでミリ秒単位に切り下げ、時間外を不足計上しない。最後の給与月で期間超過と所定超の通常賃金差額を清算し、不足控除は推定しない。
- 個人シフト上限960分/日・5760分/週は機能の運用上限。通常制度では会社の480分/日・2400分/週以内、さらに厳しい会社・個人上限を維持する。変形は事前所定の時刻と時間、フレックスは月/清算期間の残枠を守る。これは時間外勤務や36協定の自動許可ではない。
- `sourceRevision` は種類ごとのid/versionのソート済みJSON。暗号値ではなく全関連版を照合する。清算期間の他週の公開割当も含め、50万文字を超える運用規模は明示的に拒否する。
