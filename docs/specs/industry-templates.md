# Spec: 業界テンプレート3種の追加

- 状態: approved（利用者の電器店・農家・飲食店チェーン追加指示）
- 作成: 2026-09-12
- branch: feat/industry-templates

## 目的

現在の国内・JPYの共通基盤に、地域の電器店、作物栽培農家、1法人複数店舗の飲食チェーンのテンプレートを追加する。固有の記録と業務アクション、設定・サンプル、台本を実装し、異なる業界でも同じ基盤が働くことを実データで確認する。

## 受入基準

- AC-1: WHEN 3パックを読み込む THE SYSTEM SHALL appliance_store / farm / restaurant_chain をREST・MCP・メタデータから一貫して利用できる。
- AC-2: WHEN 管理者が業界テンプレートを選ぶ THE SYSTEM SHALL 現在の会社へ初期設定を適用し、選択した場合だけサンプルを追加し、再適用で重複を生じさせない。
- AC-3: WHEN 各業界の業務台本を実行する THE SYSTEM SHALL 固有の記録から会計・在庫・請求等の共通機能へつながり、金額・数量・状態・取消と権限を維持する。
- AC-4: WHEN 会社にパックが未適用である THE SYSTEM SHALL 固有メニュー・処理・他社参照を有効にしない。
- AC-5: WHEN 既存DBを更新する THE SYSTEM SHALL 既存のデータ・表を残し、新しいパックの表を追加する。実行時のパック選択で保存済み表を削除しない。
- AC-6: WHEN UIでテンプレートを試す THE SYSTEM SHALL 業界ごとの説明・導入状態・入口を表示し、PCとスマホで既存UIの配色と操作規約を保つ。

## 分担と詳細

パック個別の仕様は pack-appliance-store / pack-farm / pack-restaurant-chain に記載する。共通統合はruntime登録・migration・導入UI・結合試験・ガイドを担当。業務は可能な限り既存moduleの公開APIを利用する。

## 範囲外

全機能を持つ実運用ERPの完成、家電リサイクル申請・農薬法定台帳/補助金・POS端末/注文決済連携・勤怠給与・フランチャイズ精算・海外/外貨対応。サンプルの単価・原価・数量は検証用の仮定と明記する。

## 検証

各パックに冪等性・会社分離・主要フロー・逆操作のDB試験。既存DBへの追加migration、新旧全パック読込、全gate、Web型/build、実ブラウザで導入と業界固有の操作・スマホ表示を確認する。専用DBを使い業務用データを初期化しない。

AC-1〜6を実装。全gate（unit393 / DB343）、全E2E13、Web型/build、追加migration、PC/390px表示を確認。証拠と限界は [統合作業記録](../log/2026-09-12-industry-templates.md) を参照。人間の業務審査は未実施。
