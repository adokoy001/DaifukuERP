- branch: feat/workforce-platform

## 目的と実装範囲

人とAIが同じMarkdownの設計・構成・契約を参照して改修できる基盤を整え、本部、店舗/部署、一般従業員で責任を分ける勤怠・有給・経費・給与の一連の業務を追加する。業界カタログは既存5種を含め15種へ広げる。公開準備済みの旧スナップショットは更新完了まで公開しない。

勤怠はサーバー時刻による出退勤/休憩、訂正申請と承認、日次/月次確認。有給は期限付きの付与・残数・申請・重複防止・承認/差戻し。経費は本人申請→所属の承認→本部精査/精算記録。給与は有効期間を持つ条件と承認済み勤怠からの計算、控除の根拠/確認、確定・本人明細。制度値や入力未確認をゼロで埋めて確定しない。

## 受入基準

- AC-1: WHEN 開発者またはAIが改修を始める THE SYSTEM SHALL Markdownの入口からアーキテクチャ、プログラム構成、主要データ/処理、権限境界、拡張方法、検証・移行手順へ辿れ、現行実装と将来計画を区別できる。
- AC-2: WHEN 本部/拠点管理者/従業員がREST・MCP・汎用CRUD・レポートを使う THE SYSTEM SHALL 会社、担当拠点、本人の境界をANDで適用し、権限外の他人の申請・給与・拠点を閲覧/変更/集計できない。承認者は自己承認できない。
- AC-3: WHEN 従業員が勤怠を記録・訂正する THE SYSTEM SHALL サーバー時刻と監査を残し、二重打刻/不正な休憩/負の時間/競合を拒否する。確定済み期間の直接変更を拒否し、訂正は理由付きで承認する。
- AC-4: WHEN 有給を申請・承認する THE SYSTEM SHALL 有効な付与、申請日、重複と残数を検査し、同時承認でも二重消費しない。却下・取消・期限切れを一貫して扱う。制度資料と検証日を残す。
- AC-5: WHEN 経費を申請・承認・精算する THE SYSTEM SHALL 金額をDecimalで扱い、申請後の本人による改変、自己承認、別拠点への移動、二重精算を拒否する。証憑や会計仕訳との実装済み連携範囲を明示する。本人は下書き/差戻し中に写真またはPDFの領収書を添付でき、同一従業員lockと親versionを用いて提出と競合しない。添付は経費の可視性と本人/拠点境界を継承し、提出後の変更と汎用CRUDでの偽造を拒否する。
- AC-6: WHEN 給与を計算・確定する THE SYSTEM SHALL 適用期間、勤務集計、賃金条件、割増/手当/控除、端数、確認者を再現可能な明細として残し、未確認条件や承認不足での確定を拒否する。確定後は直接改変できず、本人は自分の確定明細だけを読める。
- AC-7: WHEN スマホで従業員が利用する THE SYSTEM SHALL 打刻、残数、申請、状況、給与明細をタップしやすい画面で提供する。モバイルで横はみ出しや入力消失を起こさず、送信結果/競合/権限失効を表示する。機微なデータをオフライン永続キャッシュに保存しない。
- AC-8: WHEN 管理者が業界テンプレートを選ぶ THE SYSTEM SHALL 合計15種の業務目的/対象/制約/導入後の入口を示し、各テンプレートの初期設定と少なくとも1つの固有業務シナリオを実際に操作・検証できる。同名カードだけを増やさない。
- AC-9: WHEN スキーマを更新する THE SYSTEM SHALL 追加migrationで既存データを保持し、旧版からの更新・新規導入・復元を確認する。稼働中の既存業務DBをリセットしない。
- AC-10: WHEN 公開する THE SYSTEM SHALL 全体gate、Web型/build、既存/新規E2E、権限漏れと並行実行の回帰、秘密/配布物検査を通し、MITと第三者表示を保持して新しい公開履歴に反映し、GitHubの内容とCIを確認する。接続権限が不足するときは未公開として正確に記録する。

## 制度・境界

国内JPY、通常の労働時間制を初期対象とする。給与は終了した月だけを計算する。暦日をまたぐ勤務の休日区分モデルがない初版では、打刻・訂正を保持しつつ給与自動計算を理由付きで拒否する。変形/裁量/フレックス、複雑な兼業、年末調整、法定調書/e-Tax、社会保険の自動届出、銀行振込送信、医療レセプト、介護保険請求などは適合を装わず、今回の汎用基盤と区別する。日本の制度の数値・根拠は一次資料を確認して docs/domain に残し、有効期間付き設定として扱う。

## 検証計画

権限・状態遷移・給与計算・有給消費の単体/DBテスト、自己/別拠点/別会社/失効/並行実行の拒否、スマホと本部画面のE2E、15業界の導入・再適用・固有シナリオ、追加移行、全体gate、Markdownリンク/構成と実装の照合、公開後CI。
