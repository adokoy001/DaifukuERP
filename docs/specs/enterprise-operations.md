# 認証・外部連携・グループ会計・国内給与制度の統合拡張

状態: 実装済み・ローカル統合受入済み（[検証記録](../log/2026-09-12-enterprise-operations.md)）。日付: 2026-09-12。基点: 公開main a50266f。今回の利用者要求を一つの統合リリースとして扱い、専用branch/PR/work-logにまとめる。各領域の契約と根拠は本仕様から参照する。

## 到達点

SSO/MFA、メール招待と本人再設定、POS自動連携、連結会計とFC精算、国内給与の税保険料算定/年末調整、変形・フレックス勤務を、既存の会社/拠点/本人境界と確定資料の履歴を保って実装する。外部認証・メール・POSは実サービスの設定を受け取るadapterを備え、接続先未設定を成功や配信済みと扱わない。制度資料の改定年と適用日、対象範囲をデータと計算根拠に持つ。

## 共通受入基準

- AC1: 認証を拡張したとき、本人のSSO紐付け・MFA登録/確認/回復・メール招待/再設定を期限、一回性、失効、監査、列挙攻撃対策で保護し、所属や管理権限を外部email一致だけで取得させない。
- AC2: 外部イベントを受けたとき、署名/送信元と会社・店舗対応を検証し、受信履歴・再試行・重複防止・決済/返金と会計の原資料への追跡を持つ。失敗/未知項目を黙って売上にしない。
- AC3: 連結を作成したとき、各会社の閲覧権限と勘定対応、対象期間、JPY通貨、消去/調整を検証し、単体帳簿を上書きせず連結根拠と貸借一致を保存する。FC精算は契約期間・売上基準・料率/定額・税区分・取消を明示し、二重計上を防ぐ。
- AC4: 国内給与を計算したとき、適用期間つきの税表/保険料/標準報酬/本人条件に基づくDecimal計算と端数規則を使用し、未登録条件をゼロと推定しない。月次と年末調整の入力・差額・確認・確定・取消を追跡できる。
- AC5: 勤務制度を適用したとき、事前確定する所定労働日/時間、制度の有効期間、清算期間、労使合意と上限条件を記録し、実績の時間外・深夜・休日とシフト推薦の条件に矛盾を生じさせない。
- AC6: 一般従業員・店長・本部・経理/給与・テナント管理者で同じ資料の見え方が変わるとき、REST/MCP/画面の全入口で会社/本人の再認可とDTO最小化を保つ。
- AC7: 元情報が変更/失効したとき、古い案の確定を拒否し、版競合・冪等性・取消履歴・一時障害時の入力保持を守る。秘密・token・実メール・POS顧客個人情報をログや公開sourceへ含めない。
- AC8: 全体の整合性確認後、全gate、Web型/build、実ブラウザー、移行/復元、署名/認証/メールの隔離受入を実行し、マニュアル・AI入口・STATUS・設計根拠・work-logを更新してcommit/pushする。

## 設計・検証の進め方

公式仕様・国税庁・日本年金機構・協会けんぽ・厚生労働省・ASBJなどの一次資料を確認する。競合製品の公開仕様は業務フローの比較に使い、正しさの根拠は一次資料へ遡る。認証、グループ業務、労務給与を独立に設計/実装し、共通schema生成とUI/adapter整合性は最後に統合する。

各領域の対応範囲と未対応の例外、実サービスで未検証の範囲を記録する。未確認の制度値や外部接続を成功したと扱わない。既存の利用者用DB・設定・秘密は変更せず、新規専用clusterと合成identityで受入する。
