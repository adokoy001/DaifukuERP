# GitHub 初回公開の準備（2026-09-12）

仕様: [public-release](../specs/public-release.md)。利用者は `adokoy001/DaifukuERP` への公開を希望し、MIT と公開名 `adokoy001` を選択した。実運用サービスの配信や実 DB の公開は対象外。

## 公開候補

README に起動・機能・制約・画面例、CONTRIBUTING に専用 DB と 18 件の画面試験、SECURITY に報告経路と起動設定を記載した。Issue/PR テンプレート、依存更新設定、MIT 本文、第三者通知を追加。古い管理機能・バックアップ未実装というマニュアル記述を現状に更新した。

API は既定の待受を `127.0.0.1` とし、PORT、環境名、JWT、CORS origin を検証する。外部待受や production の弱い JWT、ワイルドカード CORS を拒否する。起動失敗では生の DB ドライバエラーを表示しない。`pnpm run setup --help` / `-h` は対象や実行フラグにかかわらず計画・書込みなしでヘルプを返す。

`@fastify/swagger-ui` を 6.1.1、推移依存の `@fastify/static` を 10.1.3 に更新し、依存監査の high は 1 → 0、moderate は 2 → 1 となった。残る GHSA-67mh-4wv8-2f99 は `drizzle-kit@0.31.10` 内の `esbuild@0.18.20` の開発サーバーに関するもの。現行 CLI の利用は transform/transformSync/version で、serve は使わない。上流の固定依存を非互換 override せず残し、更新時に再評価する。無警告や無脆弱性とは表明しない。

Feather Icons 4.29.2 の正式な図形と MIT 表示を揃え、Swagger UI の配布資産と上流 5.32.6 の一致を検証して欠けていた LICENSE/NOTICE を補った。lock 内の全依存とプラットフォーム別 package の宣言ライセンスを [第三者通知](../../THIRD_PARTY_NOTICES.md) に整理した。

## プライバシーとソース配布

公開前の全 Git 履歴・現行ソース・バイナリを検査した。秘密スキャナーに加え、私的なセッションリンクや個人の環境説明を目視で点検した。元の履歴をローカルに保全し、精査したソースだけで公開履歴を開始する。元の branches/tags や `.git` は配布しない。

ソース中の不要な個人名・ホームパス・私的な背景を除き、歴史的な引継ぎは技術的な要約に置換した。スクリーンショットは合成データであることを確認。生成済みマニュアル HTML は追跡から外し、Markdown/画像/生成スクリプトを残す。実 env、DB、dump、setup 状態、資格情報、検証ランタイムはリポジトリ外に保持する。

配布スクリプトは clean な HEAD を `git archive` する方式に変更した。未追跡データと Git 履歴を含めず、追跡済みの秘密/実行時パス、未確定変更、既存出力の上書きを拒否する。

## 残る設定と範囲

GitHub の非公開脆弱性報告は現時点で未有効。SECURITY は当面「非公開連絡先を希望する」という公開 Issue だけを案内し、問題の詳細を投稿しないよう明示する。リポジトリ管理者が有効化後に案内を更新する。

TLS 終端、通信・ログインの rate limit、添付のマルウェア検査、遠隔 TLS 接続、実運用負荷、SSO/MFA、全業界・全制度への適合は未検証または対象外。実験的なソース公開として機能範囲を明示した。
