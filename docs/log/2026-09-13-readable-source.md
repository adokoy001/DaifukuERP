# 作業記録: ソース整形と行数規約の見直し

- 対象: [可読性仕様](../specs/readable-source.md)
- 規約: [整形・lint・履歴追跡](../conventions/lint.md)
- 状態: 実装済み、受入検証中。結果は検証完了後に追記する。

## 変更

Prettier 3.9.6を固定し、TS/TSX/JS/MJS/CJS/CSSを120文字目安・LFで整形した。整形のみのコミットを分け、`.git-blame-ignore-revs`へ完全SHAを記録した。format / format:checkを追加し、gateの先頭で未整形を検出する。過去migrationと生成schemaは整形対象から外し、チェックサムを保持する。

ファイル400行・関数80行に合わせた一括分割は、変更単位を増やして可読性改善を妨げるため取り下げた。行数はファイル1,000・関数300の警告へ緩和した。分割の判断は責務・結合・重複・読みやすさに置き、超過だけでCIを失敗させない。型、権限、依存境界、金額、テストの規約は維持する。

業務ロジック・DB構造・制度値・利用者データは変更しない。給与制度の版管理は別仕様とPRで扱う。

## 検証記録

独立したローカルPostgreSQLと合成データで全gate・API/Web/edge build・既存ブラウザ回帰を実行する。ライブ環境を検証用DBとして使わない。完了結果と数値は終了コードと保存ログから追記する。
