## 変更

Prettier 3.9.6を固定し、TS/TSX/JS/MJS/CJS/CSSを120文字目安・LFで整形した。整形のみのコミット `5f4e413cb4a2cb777806855ac7a4e5bff614d3f6` を分け、`.git-blame-ignore-revs`へ完全SHAを記録した。format / format:checkを追加し、gateの先頭で未整形を検出する。過去migrationと生成schemaは整形対象から外し、チェックサムを保持する。

ファイル400行・関数80行に合わせた一括分割は、変更単位を増やして可読性改善を妨げるため取り下げた。行数はファイル1,000・関数300の警告へ緩和した。分割の判断は責務・結合・重複・読みやすさに置き、超過だけでCIを失敗させない。型、権限、依存境界、金額、テストの規約は維持する。

業務ロジック・DB構造・制度値・利用者データは変更しない。給与制度の版管理は別仕様とPRで扱う。

## 整形前後の実測

基準コミット `11987615e895e7eaf248e66bb3455ef771089231` と純整形コミットを同一のファイル集合で比較した。コード集合はGit管理の `.ts` / `.tsx` / `.js` / `.mjs` / `.cjs` の1,188ファイル、本体src集合はそのうち `/src/` 配下で `.test.` と `.spec.` を除いた825ファイルである。CSS15ファイルは整形対象だが、この長行集計には含めない。文字数の閾値は「超過」で数えた。

| 対象・指標 | 整形前 | 純整形後 |
| --- | ---: | ---: |
| コード1,188ファイルの総行数 | 73,026 | 144,099 |
| 同対象の160文字超 | 5,884 | 253 |
| 同対象の200文字超 | 3,132 | 118 |
| 同対象の400文字超 | 567 | 8 |
| 同対象の最長行 | 4,633文字 | 753文字 |
| 本体src 825ファイルの総行数 | 41,382 | 84,714 |
| 同対象の160文字超 | 3,373 | 122 |
| 同対象の200文字超 | 1,973 | 59 |
| 同対象の400文字超 | 457 | 2 |
| 同対象の最長行 | 4,633文字 | 753文字 |

120文字は通常のコード配置の目安で、長い固定文字列・URL等を切断する上限ではない。整形によって圧縮された行が展開されたため、総行数は増えている。不整形入力の拒否、整形済み入力の受入れ、二度目の整形で内容が変わらないことを別のformatter契約検査でも確認した。基準コミットからの差分に既存migration・生成schemaは含まれない。

整形直後に旧400/80規約を適用した保存結果は、ファイル長エラー5件・関数長警告146件だった。最終1,000/300規約では、`MembershipEditor` 302行、`ShiftPlanner` 302行、`WorkforceReviews` 394行、`AnalyticsWorkspace` 685行の4警告が残る。空行・コメントを除いた値であり、閾値変更による警告数の減少を業務コードの複雑さの減少とはみなさない。行数だけのための分割を取り下げ、これらをレビュー対象の警告として残した。

CI・配備の実行結果はPRと私的な実行記録で別途確認する。今回の記録へ秘密の設定、利用者データ、環境固有の接続先を含めていない。

公開前の履歴スキャンでは、既存のSquare合成Webhook試験用の固定文字列を1件検出した。基準コミットと同じテスト専用値であることを確認し、そのコミット・ファイル・行の指紋だけを私的な除外記録に残して再検査した。検査全体やテストディレクトリを除外していない。
