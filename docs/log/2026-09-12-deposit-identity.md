# 2026-09-12 敷金の同一性・受領返還の保護

## 変更・判断
敷金の作成時に、入居者と部屋が契約に一致することを検証し、省略値を補う。契約・入居者・部屋は以後変更不可。受領後の金額変更も拒否する。受領/返還は敷金行をロックして最新状態から判断するため、並行した同じ操作でも一度だけ転記する。

受領/返還の日付・金額・控除・仕訳参照をserverOwnedとし、private write capabilityを持つ正規操作だけが台帳更新できる。role/row権限の回避は加えていない。receipt/returnが生成した仕訳を直接逆仕訳するという、台帳と一致しなくなる案内を削除。訂正ワークフロー未対応を正確に案内する。

既存台本は「新規会社で賃貸管理の税抜設定を明示採用する」fixtureとして初回pack.applyにforce:trueを指定。通常applyが保存済み設定を保持する新契約は変更しない。台本の全金額期待値は変更なし。受領日改ざんテストは、所有権検証がhookより先に拒否するためINVALID_STATEからPERMISSION_DENIEDへ変更した。
