# 2026-09-12 — 従業員ポータルと本部・拠点の業務画面

対象仕様: [workforce-platform](../specs/workforce-platform.md)、[backend contract](../specs/workforce-backend-contract.md)。ブランチ `feat/workforce-platform`。既存の業界画面を維持し、勤務・申請・給与の専用画面を追加した。

## 実装

- `/me`: 出退勤・休憩、提出・理由付き訂正、有給残数と申請、経費下書き・提出・取消・状態、確定済みの本人給与明細。
- `/workforce`: 拠点・月の絞込、承認待ちキュー、勤務実績・経費の履歴、会社内の候補利用者からの従業員登録、有給付与、給与計算・確定・取消。通常の拠点・制度・賃金条件画面へ接続。
- 本人の明細閲覧と本部の給与操作は別導線。自分への承認・精算・給与確定は UI でも抑止し、サーバーの境界を迂回しない。
- 領収書は経費の下書き保存後に任意で写真/PDFを添付する。型だけを公開パッケージから参照し、認証付き upload/download、親経費 version 更新、提出後の凍結に対応。
- `expectedVersion`、新規操作の同じ idempotency key による再試行、実際の FormData に基づく送信、送信中の二重操作抑止、未保存の破棄確認。失敗時は入力を保持する。
- 読込は tenant/user/company で分けたメモリー内 Query。永続オフラインキャッシュを作らず、機微情報の読込は `no-store`、不要な読込は abort。会社切替は既存のタブ単位選択とページ再読込を利用する。アクセス失効時は古い表示を隠す。
- `sites` scope と `siteIds` を会社所属編集に追加。既存の店舗限定設定を保つ。
- workflow 管理レコードの通常画面では利用不能な作成・確定・削除等を隠し、専用画面を案内する。従業員の保守更新、拠点・制度・賃金条件の通常編集は保つ。
- 紫と紺の見出し、淡い背景、状態色、44px以上の操作部品、モバイルで打刻を先に置く配置。空の承認欄を並べず、確認が必要な記録を優先する。

## 実際のブラウザで修正した点

- select の選択肢までフィールド名に含まれていたため、明確なアクセシブル名を付けた。
- 訂正入力で日付・秒を保持し、日本時間の値を送信する。端末の日付イベント差に依存せず FormData を読む。
- 経費・外部入力の控除/手当を1円単位へ揃えた。未確認の控除は空欄にし、全8項目の確認と根拠を要求する。
- 給与の対象は終了月。前月の有給1日と時給1500円・480分から12,000円を得る合成シナリオで確認し、当月の実時間打刻とは分けた。
- `pack.list` の読込エラーでも会社切替を使えるよう、業界ページの CompanyPicker を保持した。権限の再評価で管理者本人の給与を読めても、本部用の給与タブを誤表示しない。
- 前日・前月から退勤していない勤務は開始日を表示し、対象月の訂正導線を用意した。未完了の勤務時間をゼロ時間と表示せず、退勤後に集計する旨を案内する。

## 検証

- Web 単体18ファイル135件が通過（workforce 単体5件を含む）。
- Web 型検査・ESLint・本番ビルドを実行。初回 build の大きな共通チャンクの警告は残るが、workforce は遅延読込チャンクに分離される。
- 専用 PostgreSQL 16 DB `daifuku_e2e_test_workforce1` を空DB検証付き fixture で準備。既存データの削除・リセットはしていない。API 3101 / Web 5174 を使用した。
- `workforce.spec.ts` の3ケースで、本人390/375pxの操作、本部・拠点の承認・精算、領収書、確定前の非公開、確定後12,000円の本人明細、別人/別拠点の拒否、自己承認防止、会社切替、所属削除時の表示破棄、15業界の一覧・検索を確認した。
- 既存の18ケースを含む全21 E2Eが通過。その後、継続勤務の表示と画像撮影の待機を整え、workforce 3ケースも再確認した。UIの会社所属編集で `sites` scope の保存も確認した。
- 画像・trace は Playwright の `testInfo.outputPath` に出力する。全て合成従業員・申請・給与のテストデータ。マニュアルには本人スマホと本部給与の2画像を原画像のまま追加した。メールアドレス・実ホスト名・実在者の個人情報は含まない。
- ドキュメントリンク24文書226対象を確認し、マニュアル18章41画像を生成した。検証完了後、専用API 3101 / Web 5174 のプロセスを終了し、両ポートの待受がないことを確認した。既存の開発サーバーは操作していない。

## 適用範囲

日本円・通常の労働時間制の初版。制度・給与の計算範囲は backend 仕様と[日本の労務制度](../domain/japan-workforce.md)に従う。日付をまたぐ勤務は打刻・訂正として記録できるが、自動給与計算は未対応として停止する。経費の精算記録から銀行送信・自動仕訳は行わない。

利用手順は[補遺F](../manual/appendix-f-workforce.md)、独立した空DBからの E2E 再現は [CONTRIBUTING](../../CONTRIBUTING.md) を参照。
