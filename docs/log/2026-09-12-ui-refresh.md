# 2026-09-12 UI refresh

## 変更
パール調の背景・藍色サイドバー・紫/シアン/コーラルの配色、独自SVGアイコン、実件数の概況カード、業務カード、レポートと作業ガイドを追加。ログイン、表、フォーム、モバイルナビゲーションを統一。架空の売上・増減率は使用しない。

FieldMeta.serverOwned/readOnly/defaultValue を解釈し、計算項目を公開入力・必須検証から除外。既定 true/enum/JSON を表示。読み取り権限のみの利用者には保存を出さず入力をロック。参照値は名前/番号/コードを優先する。品目選択時に摘要・単価・税区分・単位を利用可能な明細列へ補完する。

未保存値と読み込み時のversionを保持し、バックグラウンド再取得で上書きしない。保存/文書操作を相互に無効化し、未保存時は確認を挟まず確定できない。移動/閉じる際の保護、保存の二重送信防止、競合リロードを維持。文書操作は確認ダイアログと expectedVersion を使用、取消は任意の訂正日を指定可能。ログアウトも未保存確認後にセッションを消す。

フォーム/JSON切替で入力を引き継ぎ、構文/必須エラー時は切替を止める。CSV は数式として解釈されるテキストを無害化し、負の数値は保持。伝票一覧の番号・状態の重複列を除去。文書明細は独立したマスター一覧から除外。
